## 2. 生产启动实测（scripts/start-local.mjs）

隔离数据目录与端口，避免触碰用户 `.data`：

```powershell
$env:BRAIN_DATA_DIR="$PWD\.tmp-probe-data"; $env:APP_HOST="127.0.0.1"; $env:APP_PORT="3199"
$env:APP_ORIGIN="http://127.0.0.1:3199"; $env:NODE_ENV="production"
node scripts/start-local.mjs start
```

观察到的输出：

```
▲ Next.js 16.3.5
- Local:         http://127.0.0.1:3199
- Network:       http://127.0.0.1:3199
✓ Ready in 135ms
✓ Running next.config.ts took 42ms
```

结论：production build 能在本机回环地址启动并进入 Ready。该进程由外部超时终止
（运行 98s 后被 kill），不是服务自身崩溃。收尾核验：端口 3000/3199 无监听残留，
无 `node` 进程残留，`.tmp-probe-data` 已清理。
