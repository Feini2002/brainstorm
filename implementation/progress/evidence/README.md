# 实施证据目录

这里存放**实际执行**的运行证据：命令、退出码、最小输入、预期与实际差异、失败定位入口。
每份证据按 Gate 归档（`G0.md`、`G1.md`、…），对应的说明性报告在 `docs/progress/`。

规则：

- 只记录真实跑过的命令与观察结果。未执行的用例只能标为「未执行」或「环境阻塞」，
  不允许用「应当会通过」代替。
- 不存 API Key、原文全库或完整模型请求；需要引用文本时只留最小片段与实体 ID。
- 使用测试替身的结果必须写明是替身，不得写成真实外部服务已通过。
- 失败样本保留脱敏后的复现命令；临时数据目录在收尾时清理。

文档包自身的审计结果放在仓库根目录 `DELIVERY_AUDIT.md` 与 `audit/` 下，与本目录的实施证据不是一回事。
