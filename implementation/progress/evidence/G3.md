## 4. 实测数字（不是估算）

**画布预算与降级（T052-C04b）**：按 `limits.graphNodes = 200` 播种 200 条记录并打同一个标签，
`POST /api/graph?filter.tagId` 返回

```
scope.matchedNodeCount = 200
scope.shownNodeCount   = 200
scope.truncated        = false
```

即「正好等于预算」不算截断，两个计数一致。页面摘要同时显示「知识库合计」，所以 200 不等于
「库里只有 200 条」。

**长标题（T052-C04b）**：`limits.titleCodePoints = 100`。

```
PATCH 标题 = 100 码点   → 200
PATCH 标题 = 101 码点   → 400
offsetWidth/offsetHeight  → 208 × 84（= NODE_WIDTH × NODE_HEIGHT）
aria-label                → "打开记录：<完整标题>"，title = "<完整标题>"
```

即：截断只发生在呈现层，可回溯的完整标题仍然在无障碍名称与 tooltip 上；节点尺寸与交给 Dagre 的
尺寸一致。

**异常图集（T052-C04）**：6 个节点（3 个成环 + 1 个孤立 + 1 个第二分量 2 节点）、4 条边。
自动布局后 6 个节点的 `transform` 互不相同，`graph-save-error` 计数为 0。

**过期派生（T051）**：改原文 → 边 `isStale = true`、`freshness.byRelationId[edgeId] = 'stale'`、
`reviewStatus` 仍为 `accepted`、`sourceRawVersion` 仍为 1。只改标题 → `revision` 前进、
`rawVersion` 不变、`isStale = false`。保存布局 → 视图 `revision + 1`，关系的
`staleCount` / `freshCount` 一字不变。

**规模与耗时（T050-C01，T052-R06）**：环境 Windows 10.0.22631 · Node 24.18 · 本机 Chromium ·
1280×720 视口 · 隔离数据目录 `tests/e2e/.data`（非用户库）。数据 = 60 条真实记录（标签筛选
范围的视图，因为显式选择上限是 `selectedItemsPerProjection = 40`）。`test.info()` 的 `timing`
注解实测：

```
节点 60：打开 530ms、自动布局 105ms、拖动 536ms
```

这三项在 `graph-accessibility.spec.ts` 里另有宽松上限（打开 < 20s、布局 < 30s），用来抓真正的
崩塌（二次复杂度布局、未批量的写入风暴），不因普通抖动而失败。**不声称**超出 `graphNodes`
预算（200）的能力。

**拖动落库（T051-C03）**：拖动前存储视图 `revision = 1`、`positions[left] = {50, 50}`；拖动后轮询
到 `revision > 1` 且坐标不再是 `{50, 50}`，同时 `POST /api/graph` 的 freshness 与拖动前完全一致。

## 5. 关键断言的意图（为什么这么写）

- **`T052-C01` 按 id 比对图读与库读**，而不是数画布上有几个方块：硬编码数组同样能画出两个节点。
- **`T051-C02` 特意只改标题**：`updatedAt` 与 `revision` 都动了，只有 `rawVersion` 没动。用时间戳
  或 revision 判断过期的实现会在这里失败，而按 `rawVersion` 判断的实现会通过。
- **`T051-C03` 先在拖动前读一次存储行**：拖动是防抖自动提交的，拖动后再读基线会与计时器竞态，
  「没变化」也可能是断言自己读晚了。
- **`T052-C04b` 用 `offsetWidth` 而不是 `boundingBox()`**：后者在屏幕空间，被 `fitView` 缩放，
  208px 会读成 216px。
- **`T052-C06` 读源码而不是断言注释**：先把注释剥掉再扫描，否则「这里不许用 SQL」这句注释本身
  就成了命中项。

## 7. 本轮修复的缺陷与复现方式

| 缺陷 | 复现 | 修复后 |
| --- | --- | --- |
| 全库派生新鲜度导致「端点已删除」误报 | 建一条关系，只把一端放进读取范围，读图 | 只对两端版本都在窗口内的关系派生；范围外的关系不参与计数，也不显示为 missing |
| 检查面板看不到关系依据 | 选中一条 AI 建议边 | `GraphEdge.evidence` 随图读返回，面板逐条显示引文与出处 |
| 视口外拖动静默失效 | 用 `boundingBox()` 的中心点对折叠线以下的节点发鼠标事件 | `dragNode()` 先 `scrollIntoViewIfNeeded` 并断言节点完整落在视口内 |
| `boundingBox()` 缩放导致尺寸误判 | 对已 `fitView` 的画布读节点宽度 | `nodeLayoutSize()` 读 `offsetWidth/offsetHeight` |
| 与防抖计时器竞态 | 拖动后立刻读存储行作基线 | 拖动**前**读基线，拖动后轮询到 revision 前进 |
