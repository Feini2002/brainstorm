## 3. 关键缺陷与修复（本 Gate 暴露）

| 缺陷 | 现象 | 修复 |
| --- | --- | --- |
| `RELATION_COLUMNS` 未加 `r.` 前缀 | 关系查询 JOIN `knowledge_items` 两次，报 `ambiguous column name: id` | 全部列限定为 `r.*`（T022 集成测试发现） |
| `decodeEvidence` 按 `item_id` 读取 | 与 DTO/存储约定的 `itemId` 不一致，读到 `undefined` 抛错 | 改为读 `itemId`，兼容旧 `item_id` |
| 同键人工关系被当作错误 | 对称关系反向提交本应幂等，却返回 400 | 改为返回既有记录 + `created: false` |
| `next/font/google` 远程字体 | 违反 T024-R01 离线承诺 | 移除，改为纯本地字体栈 |
| `decodeItemRow` 依赖 `capture_request_id` | 列表查询未选择该列，详情路径才会暴露 | **已记录，尚未修复**；补列表回归测试时一并验证 |
