# T030 验收用例｜模型错误脱敏与安全日志


本文件是**测试规格**，不是测试结果。实施入口：[T030 模型错误脱敏与安全日志](../../04_tasks/G2/T030_redaction.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：放入可搜索但不可用的秘密标记，捕获请求头和出站目标，扫描响应、日志、浏览器存储与导出内容。

基线与状态：来源校验结果、秘密可见性、出站调用计数及受保护数据。

整个用例组不可违反：被拒绝行为没有写入和付费副作用，秘密标记不进入任何公开或可分享产物。

清理方法：撤销测试配置、删除测试秘密、关闭恶意测试页面，并确认正式安全设置没有被测试改弱。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T030-C01｜头部泄露

**前置：** transport错误包含Authorization对象。

**动作：** 经过logger记录。

**必须断言：** 日志中秘密被替换且字段不回显。

**必须排除：** 常见调试代码会完整打印请求头。



## T030-C02｜字符串嵌入

**前置：** 供应商错误把Key嵌入message。

**动作：** 返回给UI。

**必须断言：** 秘密值不出现在响应或日志。

**必须排除：** 仅按字段名过滤无法覆盖字符串泄露。



## T030-C03｜超长正文

**前置：** 错误返回一大段HTML或笔记回显。

**动作：** 处理失败。

**必须断言：** 只保留限长安全摘要和状态码。

**必须排除：** 错误路径也可能成为数据外泄通道。



## T030-C04｜路径堆栈

**前置：** DB错误含本机用户目录。

**动作：** 查看浏览器错误。

**必须断言：** 只见关联ID与通用说明。

**必须排除：** 路径也属于不必要的个人信息。



## T030-C05｜日志检索

**前置：** 完成设置、测试、整理、失败流程。

**动作：** 扫描生成文件与控制台记录。

**必须断言：** 无测试秘密标记。

**必须排除：** 单一路径安全不代表所有分支安全。



## T030-C06｜诊断分享

**前置：** 用户导出故障摘要。

**动作：** 检查内容。

**必须断言：** 只有白名单环境与代码，不含原文Key。

**必须排除：** 诊断包不应成为整库备份的别名。
