# T041 验收用例｜模型用量、输入范围与错误诊断


本文件是**测试规格**，不是测试结果。实施入口：[T041 模型用量、输入范围与错误诊断](../../04_tasks/G2/T041_llm_diagnostics.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：核对日志事件、响应摘要、用量来源和关联ID，同时扫描所有产物中的秘密与原文标记。

基线与状态：日志字段、计数、错误分类、运行用量与诊断文件。

整个用例组不可违反：诊断读取不改变知识和Run，不引入第三方遥测，也不通过分享摘要扩散私人内容。

清理方法：清理测试日志并检查轮转限制，保持正式日志策略和受保护接口不变。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T041-C01｜usage缺失

**前置：** 供应商不返回用量。

**动作：** 展示Run详情。

**必须断言：** 显示未知，不用字数换算伪造精确token。

**必须排除：** 缺失数据不能被估计伪装为观测。



## T041-C02｜格式修复

**前置：** 一次整理发生一次修复。

**动作：** 查看请求计数。

**必须断言：** 显示两次外部尝试。

**必须排除：** 用户需要理解实际消费动作。



## T041-C03｜限流错误

**前置：** 供应商返回429。

**动作：** 查看诊断。

**必须断言：** 提示限流或配额相关问题，不假造余额。

**必须排除：** 错误码不能推导账户具体剩余额度。



## T041-C04｜安全复制

**前置：** 用户复制故障摘要。

**动作：** 搜索测试秘密和原文标记。

**必须断言：** 两者都不存在。

**必须排除：** 分享故障不应分享私人知识。



## T041-C05｜超时说明

**前置：** 用户中止或超时。

**动作：** 查看提示。

**必须断言：** 说明调用结束不代表供应商一定未计费。

**必须排除：** 本地Abort不能控制外部结算事实。



## T041-C06｜来源范围

**前置：** 整理使用三十候选。

**动作：** 查看运行详情。

**必须断言：** 显示实际三十而非固定四十。

**必须排除：** 预算上限不等于实际发送量。
