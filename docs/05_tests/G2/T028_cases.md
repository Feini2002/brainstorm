# T028 验收用例｜Base URL规范化与出站信任边界


本文件是**测试规格**，不是测试结果。实施入口：[T028 Base URL规范化与出站信任边界](../../04_tasks/G2/T028_endpoint_policy.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：放入可搜索但不可用的秘密标记，捕获请求头和出站目标，扫描响应、日志、浏览器存储与导出内容。

基线与状态：来源校验结果、秘密可见性、出站调用计数及受保护数据。

整个用例组不可违反：被拒绝行为没有写入和付费副作用，秘密标记不进入任何公开或可分享产物。

清理方法：撤销测试配置、删除测试秘密、关闭恶意测试页面，并确认正式安全设置没有被测试改弱。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T028-C01｜网关前缀

**前置：** baseUrl含/api/openai/v1。

**动作：** 构造最终请求地址。

**必须断言：** 前缀完整保留且只追加一次chat/completions。

**必须排除：** URL相对路径规则常导致请求发错位置。



## T028-C02｜双端点

**前置：** 用户粘贴完整/chat/completions。

**动作：** 保存配置。

**必须断言：** 提示填写API根地址，不产生重复端点。

**必须排除：** 错误地址会被误判为模型不可用。



## T028-C03｜凭据URL

**前置：** 地址包含user:pass或token查询。

**动作：** 提交设置。

**必须断言：** 拒绝并让用户改用Key输入框。

**必须排除：** URL会出现在日志与浏览历史中。



## T028-C04｜重定向

**前置：** 受信服务返回302到另一域名。

**动作：** 测试连接。

**必须断言：** 明确失败且不携带Key跟随。

**必须排除：** 跨域重定向可能泄露凭据。



## T028-C05｜笔记诱导

**前置：** 原文要求把请求发往另一个地址。

**动作：** 执行整理。

**必须断言：** 仍只请求已保存endpoint。

**必须排除：** 知识材料不应拥有网络配置权限。



## T028-C06｜HTTP私网

**前置：** 用户填写http回环或内网IP。

**动作：** 提交配置。

**必须断言：** 说明当前MVP不支持并拒绝。

**必须排除：** 不要以兼容方便为由无限扩大服务端网络能力。
