# T031 验收用例｜OpenAI兼容HTTP适配器


本文件是**测试规格**，不是测试结果。实施入口：[T031 OpenAI兼容HTTP适配器](../../04_tasks/G2/T031_llm_transport.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：使用可注入transport记录endpoint、调用次数、消息字段、超时和响应形态；同时比对Run与数据库结果。

基线与状态：输入快照、候选集合、格式档位、尝试次数与最终Run状态。

整个用例组不可违反：原文已经持久保存，Key不进入messages，失败与重试不会产生不可见额外请求。

清理方法：终止本用例transport与计时器，清理临时Run；真实连接测试另行记录而不混入固定回归。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T031-C01｜最小兼容

**前置：** 测试服务只支持基础ChatCompletions字段。

**动作：** 发送prompt_json请求。

**必须断言：** 不带多余temperature和结构化参数且能解析。

**必须排除：** 过度参数化会让兼容接口变成不可用。



## T031-C02｜不支持JSON档位

**前置：** 服务返回response_format不支持。

**动作：** 执行json_object请求。

**必须断言：** 明确失败并建议手动改档位，不自动再发。

**必须排除：** 隐藏降级会增加费用且难以解释行为。



## T031-C03｜截断输出

**前置：** finish_reason表示length。

**动作：** 处理响应。

**必须断言：** 标记输出不完整，不尝试把残片当有效结果。

**必须排除：** JSON偶然可解析也可能缺重要内容。



## T031-C04｜空内容

**前置：** message.content为null或空串。

**动作：** 解析响应。

**必须断言：** 返回EMPTY_MODEL_OUTPUT类错误。

**必须排除：** 空响应不能被包装成成功整理。



## T031-C05｜响应过大

**前置：** 服务持续返回超过预算。

**动作：** 读取响应流。

**必须断言：** 到上限立即中止并报告超限。

**必须排除：** 无限读取可能耗尽本机内存。



## T031-C06｜工具调用

**前置：** 模型返回tool_calls并请求执行动作。

**动作：** 处理结果。

**必须断言：** 拒绝非支持形态，不执行任何工具。

**必须排除：** 整理模型没有系统操作权限。
