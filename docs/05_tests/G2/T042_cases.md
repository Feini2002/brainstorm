# T042 验收用例｜AI闭环与真实连接验收


本文件是**测试规格**，不是测试结果。实施入口：[T042 AI闭环与真实连接验收](../../04_tasks/G2/T042_ai_acceptance.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：保存命令、退出码、测试ID、最小输入和预期实际差异，必要时附安全截图及数据库观察。

基线与状态：用例结果、Gate状态、临时数据、报告与明确未执行项。

整个用例组不可违反：测试不触碰用户数据库和可用Key，不自动修改架构来迎合断言。

清理方法：关闭测试服务和浏览器、清理独立目录，保留脱敏失败样本与可重复执行命令。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T042-C01｜相关材料

**前置：** 两条观点讨论同一主题。

**动作：** 真实整理。

**必须断言：** 允许合理关系或保守不连，但证据必须正确。

**必须排除：** 只看有无边会奖励模型乱连。



## T042-C02｜无关材料

**前置：** 软件观点与咖啡记录混合。

**动作：** 整理。

**必须断言：** 不得为了完成指标强行相连。

**必须排除：** 图谱质量依赖克制。



## T042-C03｜相反主张

**前置：** 两条材料立场相反。

**动作：** 整理。

**必须断言：** 保留不同立场，可能建议contradicts且可审核。

**必须排除：** 摘要不能把分歧抹成一致。



## T042-C04｜真实Key缺失

**前置：** 环境没有可用配置。

**动作：** 执行Gate2测试。

**必须断言：** 确定性部分可完成，真实调用列为未执行。

**必须排除：** 不能虚报端到端模型接入成功。



## T042-C05｜人工修改

**前置：** 用户手改摘要后重整。

**动作：** 真实模型返回另一摘要。

**必须断言：** 人工内容保持。

**必须排除：** 工程控制比模型是否愿意遵守提示更可靠。



## T042-C06｜中断恢复

**前置：** 真实或替身请求中停止程序。

**动作：** 重启检查。

**必须断言：** Run可恢复为中断，原文不丢。

**必须排除：** 最小AI系统也要能解释失败状态。
