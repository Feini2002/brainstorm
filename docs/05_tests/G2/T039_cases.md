# T039 验收用例｜AI关系证据、去重与拒绝保护


本文件是**测试规格**，不是测试结果。实施入口：[T039 AI关系证据、去重与拒绝保护](../../04_tasks/G2/T039_relation_apply.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：先读取目标及依赖实体的版本、状态和关系，再触发动作并复核所有应变与不应变字段。

基线与状态：Item revision/rawVersion、Relation审核与证据、Run终态或View来源。

整个用例组不可违反：原文不会无提示消失，人工修改不被静默覆盖，迟到响应不复活已终止操作。

清理方法：恢复本用例专用fixture并清理运行记录；对不可逆动作使用隔离数据库而不是回滚真实资料。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T039-C01｜虚构ID

**前置：** 模型返回候选外UUID。

**动作：** 应用建议。

**必须断言：** 该关系被拒绝或整结果按规范失败，不入库。

**必须排除：** 模型看似合理的链接也可能不存在。



## T039-C02｜假摘录

**前置：** quote不是任一原文子串。

**动作：** 校验证据。

**必须断言：** 拒绝该边并说明证据不匹配。

**必须排除：** 有引号不代表真的引用过来源。



## T039-C03｜对称排序

**前置：** 当前ID字典序较大且关系对称。

**动作：** 规范化后保存。

**必须断言：** 两个端点的rawVersion和证据仍对应正确条目。

**必须排除：** 仅交换ID会产生来源错配。



## T039-C04｜低分建议

**前置：** score为0.69。

**动作：** 处理关系。

**必须断言：** 不进入默认建议，Item整理仍成功。

**必须排除：** 少连线优于把所有相近内容连成网。



## T039-C05｜人工覆盖

**前置：** 相同边已manual accepted。

**动作：** 模型提出不同理由。

**必须断言：** 保留人工内容不降级。

**必须排除：** 自动化不能抢回用户控制权。



## T039-C06｜全部无效

**前置：** 所有关系都因证据或评分被过滤。

**动作：** 完成整理。

**必须断言：** 元数据可成功保存，关系为空并有诊断计数。

**必须排除：** 验收不能强制模型至少造一条边。
