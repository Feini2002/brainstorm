# T038 验收用例｜整理字段应用与人工保护


本文件是**测试规格**，不是测试结果。实施入口：[T038 整理字段应用与人工保护](../../04_tasks/G2/T038_metadata_apply.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：先读取目标及依赖实体的版本、状态和关系，再触发动作并复核所有应变与不应变字段。

基线与状态：Item revision/rawVersion、Relation审核与证据、Run终态或View来源。

整个用例组不可违反：原文不会无提示消失，人工修改不被静默覆盖，迟到响应不复活已终止操作。

清理方法：恢复本用例专用fixture并清理运行记录；对不可逆动作使用隔离数据库而不是回滚真实资料。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T038-C01｜保护摘要

**前置：** summary被人工锁定。

**动作：** 模型提供新摘要与标签。

**必须断言：** 摘要不变，未锁标签可应用。

**必须排除：** 手工精修成果不能被批量更新抹掉。



## T038-C02｜全锁字段

**前置：** 六个整理字段都被锁。

**动作：** 执行模型结果应用。

**必须断言：** 运行结束且说明未覆盖字段，原值全保留。

**必须排除：** 空应用不是系统失败也不能偷偷解除锁。



## T038-C03｜原文不可改

**前置：** 模型输出额外rawText。

**动作：** 执行schema与应用。

**必须断言：** 额外字段被拒绝，不改原文。

**必须排除：** 模型不能重写自己的输入来源。



## T038-C04｜版本冲突

**前置：** 用户在模型期间只改title。

**动作：** 提交旧结果。

**必须断言：** 按revision冲突停止，不覆盖任何字段。

**必须排除：** 即使原文未变也可能覆盖人工新意图。



## T038-C05｜标签归一

**前置：** 模型返回AI和ai。

**动作：** 应用结果。

**必须断言：** 复用同一tagId并有序去重。

**必须排除：** 模型路径应与人工路径共享规则。



## T038-C06｜一次版本

**前置：** 应用多个字段和标签。

**动作：** 比较revision。

**必须断言：** 整体只增加一次且事务一致。

**必须排除：** 每字段加版本会让来源快照难以解释。
