# T036 验收用例｜整理主流程与事务切点


本文件是**测试规格**，不是测试结果。实施入口：[T036 整理主流程与事务切点](../../04_tasks/G2/T036_organize_orchestration.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：使用可注入transport记录endpoint、调用次数、消息字段、超时和响应形态；同时比对Run与数据库结果。

基线与状态：输入快照、候选集合、格式档位、尝试次数与最终Run状态。

整个用例组不可违反：原文已经持久保存，Key不进入messages，失败与重试不会产生不可见额外请求。

清理方法：终止本用例transport与计时器，清理临时Run；真实连接测试另行记录而不混入固定回归。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T036-C01｜先保存保证

**前置：** Item已创建且模型立即失败。

**动作：** 执行整理。

**必须断言：** 原文仍可读取，Run失败可解释。

**必须排除：** AI失败不能回滚采集。



## T036-C02｜网络不锁库

**前置：** 模型请求被替身延迟。

**动作：** 同时保存另一条新笔记。

**必须断言：** 新保存正常完成，不等待LLM释放数据库锁。

**必须排除：** 跨网络事务会冻结整个本机应用。



## T036-C03｜提交冲突

**前置：** 模型期间用户修改原文。

**动作：** 模型返回并尝试提交。

**必须断言：** Run进入conflict，人工新版不变。

**必须排除：** 旧结果覆盖新输入是数据损坏。



## T036-C04｜部分写失败

**前置：** 标签写入阶段故障。

**动作：** 完成提交事务。

**必须断言：** 元数据关系与Run成功标记全部回滚。

**必须排除：** 半整理会使多个视图读到不一致状态。



## T036-C05｜删除竞态

**前置：** 模型期间目标被删除。

**动作：** 迟到响应提交。

**必须断言：** 不重建Item，记录缺失或冲突。

**必须排除：** 删除必须是可依赖的用户决定。



## T036-C06｜关闭浏览器

**前置：** 操作请求仍在执行。

**动作：** 关闭再打开页面。

**必须断言：** 根据Run真实状态展示，不承诺后台一定完成。

**必须排除：** 请求生命周期与队列持久性不同。
