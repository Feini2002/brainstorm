# T040 验收用例｜运行恢复、迟到响应与局部轮询


本文件是**测试规格**，不是测试结果。实施入口：[T040 运行恢复、迟到响应与局部轮询](../../04_tasks/G2/T040_run_recovery.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：先读取目标及依赖实体的版本、状态和关系，再触发动作并复核所有应变与不应变字段。

基线与状态：Item revision/rawVersion、Relation审核与证据、Run终态或View来源。

整个用例组不可违反：原文不会无提示消失，人工修改不被静默覆盖，迟到响应不复活已终止操作。

清理方法：恢复本用例专用fixture并清理运行记录；对不可逆动作使用隔离数据库而不是回滚真实资料。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T040-C01｜租约过期

**前置：** Run已超过deadline仍running。

**动作：** 调用恢复逻辑。

**必须断言：** 进入interrupted且条目不再永久processing。

**必须排除：** 崩溃后没有恢复会卡住知识条目。



## T040-C02｜HMR不误判

**前置：** 有效Run仍在期限内。

**动作：** 触发开发热更新再读取。

**必须断言：** 仍显示running。

**必须排除：** 热更新不等于进程内任务已经死亡。



## T040-C03｜迟到竞争

**前置：** 恢复先置interrupted。

**动作：** 旧模型响应尝试提交。

**必须断言：** 被条件检查拒绝。

**必须排除：** 终态必须单向不可复活。



## T040-C04｜新运行保护

**前置：** 旧Run恢复时Item已指向新Run。

**动作：** 执行清理。

**必须断言：** 不改变新Run的processing显示。

**必须排除：** 旧恢复不能污染新的用户操作。



## T040-C05｜隐藏暂停

**前置：** 浏览器切到后台标签页。

**动作：** 观察轮询请求。

**必须断言：** 暂停或显著停止，回来后刷新状态。

**必须排除：** 无界轮询浪费本机资源且增加日志噪声。



## T040-C06｜终态停止

**前置：** Run已succeeded。

**动作：** 继续观察页面。

**必须断言：** 停止定时请求并读取最终结果。

**必须排除：** 完成后仍轮询会形成全站性能债。
