# T032 验收用例｜连接测试与能力验证


本文件是**测试规格**，不是测试结果。实施入口：[T032 连接测试与能力验证](../../04_tasks/G2/T032_connection_test.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：使用可注入transport记录endpoint、调用次数、消息字段、超时和响应形态；同时比对Run与数据库结果。

基线与状态：输入快照、候选集合、格式档位、尝试次数与最终Run状态。

整个用例组不可违反：原文已经持久保存，Key不进入messages，失败与重试不会产生不可见额外请求。

清理方法：终止本用例transport与计时器，清理临时Run；真实连接测试另行记录而不混入固定回归。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T032-C01｜有效连接

**前置：** 测试服务能返回规定JSON。

**动作：** 点击测试。

**必须断言：** 传输和结构均成功，配置未自动保存。

**必须排除：** 测试和保存是不同用户意图。



## T032-C02｜错误Key

**前置：** 服务返回401。

**动作：** 点击测试。

**必须断言：** 提示鉴权失败而非笼统网络故障。

**必须排除：** 用户需要知道先修哪一项配置。



## T032-C03｜模型不存在

**前置：** 服务返回模型错误。

**动作：** 测试。

**必须断言：** 提示模型标识或可用权限问题。

**必须排除：** 200网络可达不能代表模型可用。



## T032-C04｜非结构响应

**前置：** 服务返回普通OK文本。

**动作：** JSON能力测试。

**必须断言：** 传输成功但格式失败。

**必须排除：** 只要求回复OK无法验证正式整理契约。



## T032-C05｜未发送笔记

**前置：** 数据库已有私人内容。

**动作：** 观察测试请求body。

**必须断言：** 只含固定最小测试消息。

**必须排除：** 连接测试不需要泄露用户知识。



## T032-C06｜连续点击

**前置：** 测试进行中重复触发。

**动作：** 观察外部调用计数。

**必须断言：** 只保留一个活动请求并明确忙碌。

**必须排除：** 按钮重复会造成无价值费用。
