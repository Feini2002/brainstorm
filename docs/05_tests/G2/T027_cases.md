# T027 验收用例｜模型设置表单与Key输入口


本文件是**测试规格**，不是测试结果。实施入口：[T027 模型设置表单与Key输入口](../../04_tasks/G2/T027_settings_ui.md)。所属 Gate：G2。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：用可访问角色和稳定测试标识定位控件，记录用户动作前后的DOM、请求参数和服务端读取结果。

基线与状态：页面草稿、选中ID、按钮状态、服务器返回的版本。

整个用例组不可违反：没有由导航或重渲染触发的额外付费调用，没有把失败提示当成保存成功。

清理方法：关闭抽屉并清理组件，重新读取服务端状态；测试草稿不进入用户浏览器长期存储。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T027-C01｜首次配置

**前置：** 当前没有Key。

**动作：** 填写地址模型和新Key保存。

**必须断言：** 服务端存配置，前端清空Key输入并显示已配置。

**必须排除：** 成功后持续在DOM保留Key增加泄露面。



## T027-C02｜修改模型

**前置：** 已有Key但输入框为空。

**动作：** keyAction为keep仅改model。

**必须断言：** 原Key不被清空或变成星号。

**必须排除：** 空输入语义不清会破坏可用连接。



## T027-C03｜主动删除

**前置：** 用户选择delete。

**动作：** 确认并保存。

**必须断言：** 秘密被删除且AI不可用，但笔记不受影响。

**必须排除：** 删除Key不能误删知识库。



## T027-C04｜未保存测试

**前置：** 已存配置A，表单改成B。

**动作：** 点击测试但不保存。

**必须断言：** 测试B，持久化配置仍A。

**必须排除：** 测试按钮不应隐式覆盖运行配置。



## T027-C05｜更换域名

**前置：** 已有Key且Base URL改为新origin。

**动作：** 直接点击保存。

**必须断言：** 要求显式确认或重新输入，不默默转发旧Key。

**必须排除：** 凭据可能被发往用户未意识到的新服务器。



## T027-C06｜并发设置

**前置：** 两个窗口读取同一revision。

**动作：** 先保存A再保存B。

**必须断言：** B收到冲突且草稿保留。

**必须排除：** 配置覆盖会影响后续付费请求目的地。
