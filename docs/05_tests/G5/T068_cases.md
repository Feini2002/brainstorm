## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：将下载内容重新解析，检查字段集合和引用闭包，再在第二个临时库恢复并对比领域语义。

基线与状态：schemaVersion、记录数量、ID映射、秘密排除与恢复前后数据库。

整个用例组不可违反：验证不写入，失败不留半包数据，下载和恢复不触发模型调用。

清理方法：删除测试下载与临时恢复库，保留脱敏校验报告；真实备份原件不能被测试覆盖。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。
