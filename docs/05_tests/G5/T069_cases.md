# T069 验收用例｜流程可视化与逻辑保真验收


本文件是**测试规格**，不是测试结果。实施入口：[T069 流程可视化与逻辑保真验收](../../04_tasks/G5/T069_flow_acceptance.md)。所属 Gate：G5。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：保存命令、退出码、测试ID、最小输入和预期实际差异，必要时附安全截图及数据库观察。

基线与状态：用例结果、Gate状态、临时数据、报告与明确未执行项。

整个用例组不可违反：测试不触碰用户数据库和可用Key，不自动修改架构来迎合断言。

清理方法：关闭测试服务和浏览器、清理独立目录，保留脱敏失败样本与可重复执行命令。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T069-C01｜因果审查

**前置：** 材料只有两个相关观点。

**动作：** 生成演化路径。

**必须断言：** 不能无依据标causal，推测显式标出。

**必须排除：** 可视化会增强错误结论的说服力。



## T069-C02｜安全全链

**前置：** 恶意标签进入模型替身结果。

**动作：** 经过编译渲染导出。

**必须断言：** 没有脚本执行与外部加载。

**必须排除：** 单层校验通过不能代替整链测试。



## T069-C03｜异步切换

**前置：** 快速打开两个保存流程。

**动作：** 观察最终图。

**必须断言：** 显示最后选择且来源正确。

**必须排除：** 图像与来源面板不能串位。



## T069-C04｜离线恢复

**前置：** Flow保存后外网关闭。

**动作：** 重启打开。

**必须断言：** 本地渲染或安全文本降级可用。

**必须排除：** 已生成资产不应依赖模型持续在线。



## T069-C05｜格式导出

**前置：** 导出源码和JSON。

**动作：** 复核结构与来源。

**必须断言：** 一致且无秘密。

**必须排除：** 下载成功不是数据正确的全部证据。



## T069-C06｜范围记录

**前置：** 某附加格式未完成。

**动作：** 生成Gate报告。

**必须断言：** 明确未启用项，不冒充全部完成。

**必须排除：** 功能边界需要如实交付。
