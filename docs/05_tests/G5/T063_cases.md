# T063 验收用例｜流程节点、边类型与证据契约


本文件是**测试规格**，不是测试结果。实施入口：[T063 流程节点、边类型与证据契约](../../04_tasks/G5/T063_flow_document.md)。所属 Gate：G5。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：使用可注入transport记录endpoint、调用次数、消息字段、超时和响应形态；同时比对Run与数据库结果。

基线与状态：输入快照、候选集合、格式档位、尝试次数与最终Run状态。

整个用例组不可违反：原文已经持久保存，Key不进入messages，失败与重试不会产生不可见额外请求。

清理方法：终止本用例transport与计时器，清理临时Run；真实连接测试另行记录而不混入固定回归。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T063-C01｜因果不足

**前置：** 候选只有related_to关系。

**动作：** 模型返回causal边。

**必须断言：** 按证据规则拒绝或降为明确假设需符合规范。

**必须排除：** 相关不等于因果。



## T063-C02｜假设明确

**前置：** 用户要求探索一种可能路径。

**动作：** 模型使用hypothesis。

**必须断言：** 视图文字和线型明确标注推测。

**必须排除：** 推测可以有用但不能伪装事实。



## T063-C03｜悬空端点

**前置：** edge目标不在nodes。

**动作：** 校验FlowDocument。

**必须断言：** 拒绝结构。

**必须排除：** Mermaid不能替业务修复缺节点。



## T063-C04｜来源越界

**前置：** 节点引用未选择Item。

**动作：** 校验。

**必须断言：** 拒绝该结果。

**必须排除：** 生成模型只能使用授权材料。



## T063-C05｜关系越界

**前置：** edge引用不存在Relation ID。

**动作：** 校验。

**必须断言：** 拒绝引用。

**必须排除：** 虚构关系会造成假证据链。



## T063-C06｜不写领域

**前置：** Flow生成成功含新推测连接。

**动作：** 检查relations表。

**必须断言：** 没有新增由Flow自动写入的知识边。

**必须排除：** 投影推理不应自动成为权威关系。
