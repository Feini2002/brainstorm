# T067 验收用例｜流程视图保存、来源和新鲜度


本文件是**测试规格**，不是测试结果。实施入口：[T067 流程视图保存、来源和新鲜度](../../04_tasks/G5/T067_flow_history.md)。所属 Gate：G5。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：比对canonical JSON、来源ID与版本、编译哈希、DOM实例和外部请求；检查旧View是否被保留。

基线与状态：View内容、sourceSnapshot、编译版本、渲染token与过期信息。

整个用例组不可违反：生成失败不破坏旧图，浏览或重试本地渲染不重新计费，来源不被复制成独立知识。

清理方法：撤销ObjectURL并清理Renderer实例，保留安全canonical样本用于复现；删除测试View不删知识。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T067-C01｜重开流程

**前置：** 流程已生成保存。

**动作：** 刷新或重启后打开。

**必须断言：** 从canonical JSON本地重建。

**必须排除：** 保存一张截图不能支持可追溯重现。



## T067-C02｜关系被拒绝

**前置：** 流程引用某领域关系。

**动作：** 用户拒绝该关系。

**必须断言：** 流程显示依据变化。

**必须排除：** 来源关系也有版本和审核状态。



## T067-C03｜假设说明

**前置：** 流程含hypothesis边。

**动作：** 查看来源面板。

**必须断言：** 明确哪些连接是推测。

**必须排除：** 不能让来源ID掩盖推测性质。



## T067-C04｜历史保留

**前置：** 重新生成同一观察问题。

**动作：** 查看列表。

**必须断言：** 旧新两个View可比较。

**必须排除：** 生成应可追踪而不是无痕覆盖。



## T067-C05｜打开不计费

**前置：** 重复访问保存Flow。

**动作：** 统计外部请求。

**必须断言：** 零新增模型调用。

**必须排除：** 浏览结果不应重复收费。



## T067-C06｜源码派生

**前置：** 修改测试缓存源码但canonical未变。

**动作：** 重新读取。

**必须断言：** 按规范重新编译或拒绝不一致。

**必须排除：** 缓存文本不是权威知识。
