# T062 验收用例｜流程视图意图输入与材料确认


本文件是**测试规格**，不是测试结果。实施入口：[T062 流程视图意图输入与材料确认](../../04_tasks/G5/T062_flow_intent.md)。所属 Gate：G5。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：用可访问角色和稳定测试标识定位控件，记录用户动作前后的DOM、请求参数和服务端读取结果。

基线与状态：页面草稿、选中ID、按钮状态、服务器返回的版本。

整个用例组不可违反：没有由导航或重渲染触发的额外付费调用，没有把失败提示当成保存成功。

清理方法：关闭抽屉并清理组件，重新读取服务端状态；测试草稿不进入用户浏览器长期存储。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T062-C01｜引导性意图

**前置：** 用户问证明某观点一定正确。

**动作：** 生成流程请求。

**必须断言：** 提示词仍要求基于材料并标注未证实部分。

**必须排除：** 用户问题不能替代证据。



## T062-C02｜空意图

**前置：** 已选来源但观察问题为空。

**动作：** 点击生成。

**必须断言：** 按规范使用明确默认或提示填写，不产生undefined。

**必须排除：** 输入语义需要稳定约定。



## T062-C03｜修改不生成

**前置：** 用户编辑观察问题。

**动作：** 观察网络。

**必须断言：** 没有外部请求直到显式点击。

**必须排除：** 编辑每个字不应产生费用。



## T062-C04｜方向变化

**前置：** 同一来源选择LR与TB。

**动作：** 查看结果。

**必须断言：** 只改变布局方向，不改变边类型。

**必须排除：** 视觉方向不是逻辑关系。



## T062-C05｜材料缺失

**前置：** 选择后删除一个来源。

**动作：** 提交。

**必须断言：** 阻止并要求确认新集合。

**必须排除：** 缺失材料可能改变整个结论。



## T062-C06｜无依据因果

**前置：** 材料只表达相关性。

**动作：** 要求画因果关系。

**必须断言：** 系统保留关联或标假设，不当已证实因果。

**必须排除：** 图表非常容易强化不成立的逻辑。
