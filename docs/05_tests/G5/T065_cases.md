# T065 验收用例｜Mermaid严格渲染与SVG净化


本文件是**测试规格**，不是测试结果。实施入口：[T065 Mermaid严格渲染与SVG净化](../../04_tasks/G5/T065_mermaid_renderer.md)。所属 Gate：G5。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：比对canonical JSON、来源ID与版本、编译哈希、DOM实例和外部请求；检查旧View是否被保留。

基线与状态：View内容、sourceSnapshot、编译版本、渲染token与过期信息。

整个用例组不可违反：生成失败不破坏旧图，浏览或重试本地渲染不重新计费，来源不被复制成独立知识。

清理方法：撤销ObjectURL并清理Renderer实例，保留安全canonical样本用于复现；删除测试View不删知识。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T065-C01｜恶意标签

**前置：** Flow标签含img onerror等片段。

**动作：** 编译渲染净化。

**必须断言：** 没有脚本执行或外部请求。

**必须排除：** 模型数据经图引擎会进入HTML边界。



## T065-C02｜配置注入

**前置：** 输入包含试图改变securityLevel的文本。

**动作：** 处理。

**必须断言：** 配置保持strict，文本不被当指令。

**必须排除：** 用户材料不能降级渲染安全。



## T065-C03｜多图实例

**前置：** 同页预览两张图。

**动作：** 渲染与删除其中一张。

**必须断言：** SVG ID不冲突，另一张正常。

**必须排除：** 相同DOM ID会导致引用错乱。



## T065-C04｜错误清理

**前置：** Mermaid返回渲染异常。

**动作：** 切换到另一有效图。

**必须断言：** 旧临时节点不残留。

**必须排除：** 失败路径也需要清理资源。



## T065-C05｜来源点击

**前置：** 用户想查看节点原文。

**动作：** 通过旁侧面板操作。

**必须断言：** 使用真实Item ID而非任意SVG链接。

**必须排除：** 来源交互不必扩大Mermaid可执行能力。



## T065-C06｜净化后导出

**前置：** 导出当前SVG。

**动作：** 检查输出。

**必须断言：** 同样没有可执行标记。

**必须排除：** 显示安全不等于导出文件安全。
