# T064 验收用例｜受限Flow到Mermaid编译器


本文件是**测试规格**，不是测试结果。实施入口：[T064 受限Flow到Mermaid编译器](../../04_tasks/G5/T064_flow_compiler.md)。所属 Gate：G5。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：比对canonical JSON、来源ID与版本、编译哈希、DOM实例和外部请求；检查旧View是否被保留。

基线与状态：View内容、sourceSnapshot、编译版本、渲染token与过期信息。

整个用例组不可违反：生成失败不破坏旧图，浏览或重试本地渲染不重新计费，来源不被复制成独立知识。

清理方法：撤销ObjectURL并清理Renderer实例，保留安全canonical样本用于复现；删除测试View不删知识。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T064-C01｜指令注入

**前置：** 节点label包含click和初始化片段。

**动作：** 编译。

**必须断言：** 全部被当作安全文字，不形成指令。

**必须排除：** 仅关键词黑名单不足以保护自由源码。



## T064-C02｜引号括号

**前置：** 中文标签含引号和括号。

**动作：** 编译并解析。

**必须断言：** 语法合法且文字可辨认。

**必须排除：** 真实笔记常有特殊符号。



## T064-C03｜临时ID恶意

**前置：** 模型节点ID含代码字符。

**动作：** 映射编译。

**必须断言：** 改用安全内部ID，非法结构按schema拒绝。

**必须排除：** 不能让ID成为语法注入口。



## T064-C04｜推测样式

**前置：** edge.kind为hypothesis。

**动作：** 编译。

**必须断言：** 输出带推测标签的受控虚线。

**必须排除：** 视觉表达必须保留不确定性。



## T064-C05｜重复边

**前置：** 相同source target kind出现两次。

**动作：** 编译前规范化。

**必须断言：** 按规则去重，不制造重复箭头。

**必须排除：** 模型重复会降低可读性。



## T064-C06｜确定性

**前置：** 同一FlowDocument编译多次。

**动作：** 比较源码。

**必须断言：** 除明确版本字段外完全一致。

**必须排除：** 程序编译应区别于模型随机生成。
