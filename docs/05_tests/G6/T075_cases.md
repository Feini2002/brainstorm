# T075 验收用例｜密钥、跨站与渲染安全回归


本文件是**测试规格**，不是测试结果。实施入口：[T075 密钥、跨站与渲染安全回归](../../04_tasks/G6/T075_security_regression.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：放入可搜索但不可用的秘密标记，捕获请求头和出站目标，扫描响应、日志、浏览器存储与导出内容。

基线与状态：来源校验结果、秘密可见性、出站调用计数及受保护数据。

整个用例组不可违反：被拒绝行为没有写入和付费副作用，秘密标记不进入任何公开或可分享产物。

清理方法：撤销测试配置、删除测试秘密、关闭恶意测试页面，并确认正式安全设置没有被测试改弱。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T075-C01｜跨站矩阵

**前置：** 构造不同Origin与令牌组合。

**动作：** 调用读写和模型API。

**必须断言：** 非法组合均无数据和费用副作用。

**必须排除：** 安全不能只依赖一个容易漏掉的检查。



## T075-C02｜秘密全链

**前置：** 使用可搜索测试Key。

**动作：** 完成全部主要路径。

**必须断言：** 所有产物无秘密泄露。

**必须排除：** 新增功能容易绕过早期脱敏策略。



## T075-C03｜图标签攻击

**前置：** 输入不同HTML和SVG载荷。

**动作：** 渲染Markmap与Mermaid。

**必须断言：** 无执行与未声明出站请求。

**必须排除：** 图引擎是额外信任边界。



## T075-C04｜出站重定向

**前置：** 模型测试服务发302。

**动作：** 连接测试。

**必须断言：** 失败且Key不转发。

**必须排除：** 兼容代理可能存在重定向风险。



## T075-C05｜原文URL

**前置：** 笔记包含内部和外部地址。

**动作：** 保存整理浏览。

**必须断言：** 程序不自动抓取sourceRef或原文链接。

**必须排除：** 知识材料不应变成服务端抓取指令。



## T075-C06｜威胁说明

**前置：** 阅读发布安全说明。

**动作：** 核对实际措施。

**必须断言：** 不宣称本地明文Key有硬件级保护。

**必须排除：** 安全承诺不能超过实现。
