# T070 验收用例｜整库逻辑导出与秘密白名单


本文件是**测试规格**，不是测试结果。实施入口：[T070 整库逻辑导出与秘密白名单](../../04_tasks/G6/T070_full_export.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：将下载内容重新解析，检查字段集合和引用闭包，再在第二个临时库恢复并对比领域语义。

基线与状态：schemaVersion、记录数量、ID映射、秘密排除与恢复前后数据库。

整个用例组不可违反：验证不写入，失败不留半包数据，下载和恢复不触发模型调用。

清理方法：删除测试下载与临时恢复库，保留脱敏校验报告；真实备份原件不能被测试覆盖。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T070-C01｜完整字段

**前置：** 库有修改原文人工锁和审核关系。

**动作：** 导出。

**必须断言：** 关键领域字段完整保留。

**必须排除：** 只导title和summary无法恢复原始知识。



## T070-C02｜秘密白名单

**前置：** 秘密表和Run存在测试Key标记。

**动作：** 导出后全文搜索。

**必须断言：** 不存在秘密或完整请求。

**必须排除：** 黑名单删除容易遗漏新增字段。



## T070-C03｜一致快照

**前置：** 导出过程中另一请求删除条目。

**动作：** 检查导出引用。

**必须断言：** 所有引用在同一快照内一致。

**必须排除：** 混合时点会生成无法导入的备份。



## T070-C04｜超限

**前置：** 测试库逻辑输出超过大小预算。

**动作：** 导出。

**必须断言：** 明确失败不提供半截文件。

**必须排除：** 不完整备份比没有备份更危险。



## T070-C05｜中文保真

**前置：** 原文含中文emoji多行。

**动作：** 导出解析。

**必须断言：** 字节编码和字符串内容保持。

**必须排除：** 备份必须保留真实材料。



## T070-C06｜无配置依赖

**前置：** 没有Key也有笔记。

**动作：** 导出。

**必须断言：** 正常工作。

**必须排除：** 备份不应依赖模型配置。
