# T083 验收用例｜任务证据、缺陷清单与交付状态


本文件是**测试规格**，不是测试结果。实施入口：[T083 任务证据、缺陷清单与交付状态](../../04_tasks/G6/T083_release_evidence.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：保存命令、退出码、测试ID、最小输入和预期实际差异，必要时附安全截图及数据库观察。

基线与状态：用例结果、Gate状态、临时数据、报告与明确未执行项。

整个用例组不可违反：测试不触碰用户数据库和可用Key，不自动修改架构来迎合断言。

清理方法：关闭测试服务和浏览器、清理独立目录，保留脱敏失败样本与可重复执行命令。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T083-C01｜证据不足

**前置：** 任务只有实现文件没有测试结果。

**动作：** 更新状态。

**必须断言：** 不能标verified。

**必须排除：** 代码存在不等于行为正确。



## T083-C02｜失败隐藏

**前置：** 某一关键用例失败。

**动作：** 生成总报告。

**必须断言：** 明确列出并阻塞相应Gate。

**必须排除：** 平均通过率不能掩盖数据风险。



## T083-C03｜环境阻塞

**前置：** 浏览器或模型网络不可用。

**动作：** 记录结果。

**必须断言：** 使用blocked或未执行，不写通过。

**必须排除：** 环境限制需要诚实表达。



## T083-C04｜秘密包检查

**前置：** 打包交付材料。

**动作：** 扫描文件。

**必须断言：** 无真实数据库和Key。

**必须排除：** 交付过程也是安全边界。



## T083-C05｜任务映射

**前置：** 查看一个失败测试ID。

**动作：** 从报告导航。

**必须断言：** 能找到负责模块和修复范围。

**必须排除：** 没有路由的大报告难以执行。



## T083-C06｜发布硬条件

**前置：** 数据恢复或冲突保护失败。

**动作：** 尝试发布。

**必须断言：** 阻止并指向具体缺陷。

**必须排除：** 核心可靠性不能用功能数量抵消。
