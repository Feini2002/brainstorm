# T074 验收用例｜本地诊断与可观测性


本文件是**测试规格**，不是测试结果。实施入口：[T074 本地诊断与可观测性](../../04_tasks/G6/T074_diagnostics.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：核对日志事件、响应摘要、用量来源和关联ID，同时扫描所有产物中的秘密与原文标记。

基线与状态：日志字段、计数、错误分类、运行用量与诊断文件。

整个用例组不可违反：诊断读取不改变知识和Run，不引入第三方遥测，也不通过分享摘要扩散私人内容。

清理方法：清理测试日志并检查轮转限制，保持正式日志策略和受保护接口不变。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T074-C01｜受保护读取

**前置：** 没有令牌。

**动作：** 访问diagnostics。

**必须断言：** 拒绝，不能旁路读取环境资料。

**必须排除：** 诊断接口也可能泄露私人信息。



## T074-C02｜数据库锁

**前置：** 测试连接占有写锁。

**动作：** 观察错误和诊断。

**必须断言：** 定位存储层而非模型层。

**必须排除：** 分类错误会让用户修错问题。



## T074-C03｜图空白

**前置：** 容器高度为零但API成功。

**动作：** 查看客户端诊断。

**必须断言：** 提示渲染尺寸问题。

**必须排除：** 网络成功不代表可视化成功。



## T074-C04｜日志上限

**前置：** 重复触发同类失败。

**动作：** 观察日志大小。

**必须断言：** 按规则限流或轮转。

**必须排除：** 无限日志会耗尽磁盘影响保存。



## T074-C05｜安全复制

**前置：** 生成完整诊断摘要。

**动作：** 检查秘密与原文标记。

**必须断言：** 均不存在。

**必须排除：** 诊断分享边界需要自动测试。



## T074-C06｜无遥测

**前置：** 正常使用全部页面。

**动作：** 检查网络。

**必须断言：** 没有未声明的第三方统计请求。

**必须排除：** 本地工具不应暗中上传行为数据。
