# T080 验收用例｜Windows安装、启动与故障手册


本文件是**测试规格**，不是测试结果。实施入口：[T080 Windows安装、启动与故障手册](../../04_tasks/G6/T080_windows_runbook.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：在干净目录按手册逐步执行，记录终端环境、命令、退出码、路径与重启后数据抽样。

基线与状态：依赖锁定、启动进程、数据目录、构建产物与备份副本。

整个用例组不可违反：操作不改变用户全局设置，不泄露Key，不删除唯一数据副本。

清理方法：停止本次演练的进程并保留原数据与备份；仅删除明确标记为测试的安装目录。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T080-C01｜路径空格

**前置：** 项目位于中文含空格目录。

**动作：** 复制PowerShell命令。

**必须断言：** 能正确进入和启动。

**必须排除：** 未加引号路径常导致新手无法执行。



## T080-C02｜旧PATH

**前置：** 安装Node后终端仍旧版本。

**动作：** 执行预检。

**必须断言：** 提示重开终端并检查实际路径。

**必须排除：** 安装成功不代表当前会话生效。



## T080-C03｜下载失败

**前置：** npm或Chromium下载被阻断。

**动作：** 按手册排查。

**必须断言：** 区分registry代理证书和浏览器下载。

**必须排除：** 所有下载失败不应统称依赖坏了。



## T080-C04｜端口占用

**前置：** 另一个实例已运行。

**动作：** 再次启动。

**必须断言：** 解释如何确认已有进程，不乱杀所有Node。

**必须排除：** 强制结束全部进程可能影响其它项目。



## T080-C05｜日常运行

**前置：** 项目已完成构建。

**动作：** 按手册start。

**必须断言：** 无需重新安装依赖和重新输入Key。

**必须排除：** 日常使用流程应比开发流程简单。



## T080-C06｜数据保护

**前置：** 用户遇到启动失败。

**动作：** 阅读排错建议。

**必须断言：** 先备份和诊断，不删除.data。

**必须排除：** 错误修复不应以资料为代价。
