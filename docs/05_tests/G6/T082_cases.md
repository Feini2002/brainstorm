# T082 验收用例｜中文文案、状态与无障碍终审


本文件是**测试规格**，不是测试结果。实施入口：[T082 中文文案、状态与无障碍终审](../../04_tasks/G6/T082_ux_quality.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：用可访问角色和稳定测试标识定位控件，记录用户动作前后的DOM、请求参数和服务端读取结果。

基线与状态：页面草稿、选中ID、按钮状态、服务器返回的版本。

整个用例组不可违反：没有由导航或重渲染触发的额外付费调用，没有把失败提示当成保存成功。

清理方法：关闭抽屉并清理组件，重新读取服务端状态；测试草稿不进入用户浏览器长期存储。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T082-C01｜保存整理区分

**前置：** 原文已保存但AI失败。

**动作：** 阅读界面提示。

**必须断言：** 清楚知道内容仍在。

**必须排除：** 含糊失败会促使重复提交。



## T082-C02｜过期解释

**前置：** 来源原文更新。

**动作：** 查看旧View提示。

**必须断言：** 知道需重新生成而非文件坏了。

**必须排除：** 技术状态必须转成可执行用户动作。



## T082-C03｜无Key空态

**前置：** 首次进入Settings和Inbox。

**动作：** 比较文案。

**必须断言：** 不阻止记录且明确AI前提。

**必须排除：** 配置未完成不等于应用不可用。



## T082-C04｜放大字体

**前置：** 浏览器缩放到更大字号。

**动作：** 操作六页。

**必须断言：** 关键按钮仍可访问。

**必须排除：** 固定像素布局容易遮挡文字。



## T082-C05｜删除范围

**前置：** 分别删除View与Item。

**动作：** 读确认框。

**必须断言：** 明确不同影响。

**必须排除：** 相似按钮不应造成不可预期破坏。



## T082-C06｜文本替代

**前置：** 不看图只用来源列表。

**动作：** 完成材料核对。

**必须断言：** 信息完整且能回跳。

**必须排除：** 视觉形式不能成为唯一入口。
