# T076 验收用例｜领域单元测试与边界矩阵


本文件是**测试规格**，不是测试结果。实施入口：[T076 领域单元测试与边界矩阵](../../04_tasks/G6/T076_unit_suite.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：保存命令、退出码、测试ID、最小输入和预期实际差异，必要时附安全截图及数据库观察。

基线与状态：用例结果、Gate状态、临时数据、报告与明确未执行项。

整个用例组不可违反：测试不触碰用户数据库和可用Key，不自动修改架构来迎合断言。

清理方法：关闭测试服务和浏览器、清理独立目录，保留脱敏失败样本与可重复执行命令。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T076-C01｜边界长度

**前置：** 构造限制减一等于限制加一文本。

**动作：** 运行schema测试。

**必须断言：** 结果严格符合契约。

**必须排除：** 只测普通长度无法发现前后端不一致。



## T076-C02｜对称交换

**前置：** 输入不同端点顺序。

**动作：** 测试关系规范化。

**必须断言：** ID证据版本一起正确交换。

**必须排除：** 排序只改ID会留下隐藏错误。



## T076-C03｜图结构反例

**前置：** 输入环与悬空节点。

**动作：** 跑编译器测试。

**必须断言：** 在渲染前拒绝。

**必须排除：** 浏览器错误不是领域校验方案。



## T076-C04｜哈希变化

**前置：** 只修改来源revision。

**动作：** 计算指纹。

**必须断言：** 哈希变化且其它无关时间不影响。

**必须排除：** 幂等与过期检测依赖正确指纹。



## T076-C05｜随机可复现

**前置：** 同种子生成一批测试图。

**动作：** 重复运行。

**必须断言：** 相同失败案例可定位。

**必须排除：** 随机测试不能只有偶发红灯。



## T076-C06｜网络隔离

**前置：** 单元测试环境禁外网。

**动作：** 运行全套。

**必须断言：** 全部确定性用例不需要模型Key。

**必须排除：** 单元测试不应按调用收费。
