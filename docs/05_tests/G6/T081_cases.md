# T081 验收用例｜生产构建、依赖审计与发布材料


本文件是**测试规格**，不是测试结果。实施入口：[T081 生产构建、依赖审计与发布材料](../../04_tasks/G6/T081_production_audit.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：在干净目录按手册逐步执行，记录终端环境、命令、退出码、路径与重启后数据抽样。

基线与状态：依赖锁定、启动进程、数据目录、构建产物与备份副本。

整个用例组不可违反：操作不改变用户全局设置，不泄露Key，不删除唯一数据副本。

清理方法：停止本次演练的进程并保留原数据与备份；仅删除明确标记为测试的安装目录。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T081-C01｜干净构建

**前置：** 新目录只有提交文件。

**动作：** 安装构建启动。

**必须断言：** 不依赖旧node_modules或隐藏环境文件。

**必须排除：** 本机残留配置会造成虚假可运行。



## T081-C02｜生产API

**前置：** 以next start运行。

**动作：** 执行保存与整理。

**必须断言：** Node API和SQLite正常，不是只有静态页面。

**必须排除：** 静态导出无法支持本架构。



## T081-C03｜数据排除

**前置：** 检查发布材料和构建目录。

**动作：** 搜索brain.db与测试Key。

**必须断言：** 不存在真实数据和秘密。

**必须排除：** 发布包不应含个人知识库。



## T081-C04｜独立检查

**前置：** 引入lint错误再build。

**动作：** 跑完整检查链。

**必须断言：** lint失败被记录，不因build成功忽略。

**必须排除：** 检查职责必须独立。



## T081-C05｜许可记录

**前置：** 列出最终安装依赖。

**动作：** 核对版本许可位置。

**必须断言：** 与锁文件一致，不只写泛泛开源。

**必须排除：** 组件许可可能不同且会变化。



## T081-C06｜未执行项

**前置：** 真实模型或Windows无法测试。

**动作：** 生成发布报告。

**必须断言：** 明确未执行及必要操作。

**必须排除：** 可信交付不隐藏验证空白。
