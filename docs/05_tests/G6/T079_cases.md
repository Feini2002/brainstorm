# T079 验收用例｜加载、查询与图形性能预算


本文件是**测试规格**，不是测试结果。实施入口：[T079 加载、查询与图形性能预算](../../04_tasks/G6/T079_performance.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录机器、浏览器、构建类型、数据规模、冷暖状态、请求次数和可复测耗时样本。

基线与状态：时间样本、查询计数、组件实例数量、图规模与用户可操作性。

整个用例组不可违反：压测只使用合成临时数据，不把真实模型费用和本地性能混在一起。

清理方法：删除测试种子库并停止测量进程，保留原始样本与统计口径。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T079-C01｜纯记录首屏

**前置：** 生产构建只访问Inbox。

**动作：** 测资源与交互时间。

**必须断言：** 重型图形库不在初始关键路径。

**必须排除：** 输入工具不该启动就加载全部图引擎。



## T079-C02｜千条搜索

**前置：** 临时库有一千条混合文本。

**动作：** 重复受限搜索。

**必须断言：** 记录实际耗时与查询次数。

**必须排除：** 无数据样例不能证明检索能力。



## T079-C03｜最大子图

**前置：** 当前显示二百节点六百边。

**动作：** 拖动筛选。

**必须断言：** 记录可操作性并按预算降级。

**必须排除：** 数据库容量与画布展示容量不同。



## T079-C04｜轮询泄漏

**前置：** 完成所有Run后停留页面。

**动作：** 观察网络一分钟。

**必须断言：** 没有无意义持续Run轮询。

**必须排除：** 后台噪声会长期降低体验。



## T079-C05｜内存增长

**前置：** 反复打开关闭图页面。

**动作：** 观察实例与内存趋势。

**必须断言：** 不存在持续无界增长。

**必须排除：** 缺少清理会在长期使用后崩溃。



## T079-C06｜环境说明

**前置：** 输出性能报告。

**动作：** 检查测量元信息。

**必须断言：** 包含机器浏览器构建与规模。

**必须排除：** 脱离环境的快慢数字不可复用。
