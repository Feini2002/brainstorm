# T077 验收用例｜API与SQLite集成测试


本文件是**测试规格**，不是测试结果。实施入口：[T077 API与SQLite集成测试](../../04_tasks/G6/T077_api_suite.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：保存命令、退出码、测试ID、最小输入和预期实际差异，必要时附安全截图及数据库观察。

基线与状态：用例结果、Gate状态、临时数据、报告与明确未执行项。

整个用例组不可违反：测试不触碰用户数据库和可用Key，不自动修改架构来迎合断言。

清理方法：关闭测试服务和浏览器、清理独立目录，保留脱敏失败样本与可重复执行命令。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T077-C01｜真实文件

**前置：** 写入并关闭连接。

**动作：** 重开读取。

**必须断言：** 记录与版本一致。

**必须排除：** 内存替身不能证明磁盘路径正确。



## T077-C02｜并发采集

**前置：** 同键并发创建。

**动作：** 执行集成测试。

**必须断言：** 只有一条记录且响应一致。

**必须排除：** 数据库唯一约束应真正参与。



## T077-C03｜事务故障

**前置：** 元数据更新后关系写入抛错。

**动作：** 检查最终库。

**必须断言：** 全部回滚。

**必须排除：** 分层单测可能看不见跨仓储原子性。



## T077-C04｜错误一致

**前置：** 触发404409422等分支。

**动作：** 比较响应。

**必须断言：** 状态码与error.code对应。

**必须排除：** 客户端依赖稳定错误协议。



## T077-C05｜导入竞态

**前置：** 验证后出现新Item。

**动作：** 执行恢复。

**必须断言：** 原库不被覆盖。

**必须排除：** TOCTOU必须在最终提交再次检查。



## T077-C06｜安全清理

**前置：** 测试失败退出。

**动作：** 检查数据目录。

**必须断言：** 用户.data未被触碰。

**必须排除：** 测试工具本身也可能是破坏源。
