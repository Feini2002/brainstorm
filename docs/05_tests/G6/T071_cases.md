# T071 验收用例｜恢复文件校验与空库策略


本文件是**测试规格**，不是测试结果。实施入口：[T071 恢复文件校验与空库策略](../../04_tasks/G6/T071_import_validation.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：将下载内容重新解析，检查字段集合和引用闭包，再在第二个临时库恢复并对比领域语义。

基线与状态：schemaVersion、记录数量、ID映射、秘密排除与恢复前后数据库。

整个用例组不可违反：验证不写入，失败不留半包数据，下载和恢复不触发模型调用。

清理方法：删除测试下载与临时恢复库，保留脱敏校验报告；真实备份原件不能被测试覆盖。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T071-C01｜未知版本

**前置：** 备份schemaVersion为未来值。

**动作：** 校验。

**必须断言：** 拒绝并说明版本不支持。

**必须排除：** 猜测兼容可能静默丢字段。



## T071-C02｜重复ID

**前置：** 文件中两条Item同UUID。

**动作：** 校验。

**必须断言：** 指出冲突记录，整包不允许恢复。

**必须排除：** 重复身份会破坏引用含义。



## T071-C03｜悬空关系

**前置：** relation目标不在备份Items。

**动作：** 校验。

**必须断言：** 拒绝引用。

**必须排除：** 恢复后不应产生无法渲染的边。



## T071-C04｜非空目标

**前置：** 知识库已有一条Item。

**动作：** 校验或提交。

**必须断言：** 拒绝并说明只支持空库恢复。

**必须排除：** MVP不能暗中覆盖现有知识。



## T071-C05｜大文件

**前置：** 上传超过二十MiB。

**动作：** 读取请求。

**必须断言：** 及时拒绝不无限缓冲。

**必须排除：** 导入是常见内存消耗入口。



## T071-C06｜只读验证

**前置：** 合法备份被验证通过。

**动作：** 检查数据库。

**必须断言：** 仍为空，等待用户确认恢复。

**必须排除：** 测试按钮不应隐式执行破坏性写入。
