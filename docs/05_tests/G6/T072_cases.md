# T072 验收用例｜恢复事务、引用重建与回滚


本文件是**测试规格**，不是测试结果。实施入口：[T072 恢复事务、引用重建与回滚](../../04_tasks/G6/T072_import_commit.md)。所属 Gate：G6。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：将下载内容重新解析，检查字段集合和引用闭包，再在第二个临时库恢复并对比领域语义。

基线与状态：schemaVersion、记录数量、ID映射、秘密排除与恢复前后数据库。

整个用例组不可违反：验证不写入，失败不留半包数据，下载和恢复不触发模型调用。

清理方法：删除测试下载与临时恢复库，保留脱敏校验报告；真实备份原件不能被测试覆盖。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T072-C01｜往返恢复

**前置：** 导出含所有实体的库。

**动作：** 导入空临时库。

**必须断言：** 核心数据与引用等价。

**必须排除：** 备份只有经过恢复才证明可用。



## T072-C02｜中途失败

**前置：** 恢复关系阶段制造SQL错误。

**动作：** 执行导入。

**必须断言：** 全部回滚，目标仍空。

**必须排除：** 半包恢复会制造不一致知识库。



## T072-C03｜校验后变化

**前置：** 验证成功后另一请求创建Item。

**动作：** 提交导入。

**必须断言：** 重新检查并拒绝。

**必须排除：** 校验和执行之间存在竞态。



## T072-C04｜秘密保持

**前置：** 目标有已配置Key但无知识。

**动作：** 导入备份。

**必须断言：** Key不变且备份无法替换它。

**必须排除：** 知识恢复不应改变网络信任配置。



## T072-C05｜不自动整理

**前置：** 恢复上千条知识。

**动作：** 观察外部请求。

**必须断言：** 零自动模型调用。

**必须排除：** 导入不能触发巨额隐含费用。



## T072-C06｜引用ID保持

**前置：** View引用多个Item。

**动作：** 恢复后打开来源。

**必须断言：** 回跳到相同ID的真实原文。

**必须排除：** 重新随机分配ID会破坏图表来源。
