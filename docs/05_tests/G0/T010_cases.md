# T010 验收用例｜Repository 与 DTO 解码


本文件是**测试规格**，不是测试结果。实施入口：[T010 Repository 与 DTO 解码](../../04_tasks/G0/T010_repositories.md)。所属 Gate：G0。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：在真实临时文件库执行并检查行数、主外键、版本与事务回滚；关闭重开后再次读取。

基线与状态：目标表、关联表、约束、user_version与连接生命周期。

整个用例组不可违反：没有悬空引用、半事务提交或用户数据库污染；相同请求不造成重复实体。

清理方法：关闭所有测试连接，检查WAL相关文件后仅删除临时目录，不触碰应用真实.data。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T010-C01｜SQL注入文本

**前置：** 原文包含引号和SQL片段。

**动作：** 通过仓储创建和搜索。

**必须断言：** 文本原样保存且表结构不变。

**必须排除：** 字符串拼SQL可能执行用户材料里的语句。



## T010-C02｜JSON损坏

**前置：** 测试库keywords_json结构类型不对。

**动作：** 读取ItemDTO。

**必须断言：** 报告数据契约错误而不是页面崩溃。

**必须排除：** 数据库JSON有效不表示数组语义正确。



## T010-C03｜空标签

**前置：** 条目没有item_tags记录。

**动作：** 读取列表和详情。

**必须断言：** 两处tags均为空数组。

**必须排除：** null与空数组混用导致组件条件分支不一致。



## T010-C04｜并发更新

**前置：** 两个更新都携带revision=1。

**动作：** 先后提交。

**必须断言：** 仅第一条成功，第二条冲突。

**必须排除：** 最后写入无提示覆盖人工修改。



## T010-C05｜事务回滚

**前置：** 创建条目后更新标签抛错。

**动作：** 回滚外层事务。

**必须断言：** 条目和标签变化都不保留。

**必须排除：** 局部仓储自行提交会破坏原子性。



## T010-C06｜分页稳定

**前置：** 多条记录created_at相同。

**动作：** 执行两页查询。

**必须断言：** 以ID补充排序，页面间不重复遗漏。

**必须排除：** 只按时间排序会在同时间记录间漂移。
