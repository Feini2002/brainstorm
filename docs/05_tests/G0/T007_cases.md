# T007 验收用例｜本地请求令牌与来源防护


本文件是**测试规格**，不是测试结果。实施入口：[T007 本地请求令牌与来源防护](../../04_tasks/G0/T007_local_security.md)。所属 Gate：G0。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：放入可搜索但不可用的秘密标记，捕获请求头和出站目标，扫描响应、日志、浏览器存储与导出内容。

基线与状态：来源校验结果、秘密可见性、出站调用计数及受保护数据。

整个用例组不可违反：被拒绝行为没有写入和付费副作用，秘密标记不进入任何公开或可分享产物。

清理方法：撤销测试配置、删除测试秘密、关闭恶意测试页面，并确认正式安全设置没有被测试改弱。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T007-C01｜跨站写入

**前置：** 另一个网站尝试POST本机保存或整理。

**动作：** 缺少合法Origin和令牌请求。

**必须断言：** 403且数据库和模型调用计数不变。

**必须排除：** 恶意页面可能利用本地服务器代付费或改资料。



## T007-C02｜Host伪装

**前置：** 使用非配置域名指向回环地址。

**动作：** 请求session和私人API。

**必须断言：** 拒绝而不是按IP连接成功就放行。

**必须排除：** DNS重绑定会绕过仅检查网络地址的思路。



## T007-C03｜缺失令牌

**前置：** 合法页面未完成session引导。

**动作：** 调用条目GET。

**必须断言：** 返回受控拒绝并触发一次引导流程。

**必须排除：** 私人读取不应比写入更容易旁路。



## T007-C04｜重启恢复

**前置：** 浏览器持有旧进程令牌。

**动作：** 重启后读取Library。

**必须断言：** 刷新会话后成功读取，不重放旧整理POST。

**必须排除：** 把认证恢复与业务重试混在一起会重复计费。



## T007-C05｜错误来源端口

**前置：** APP_ORIGIN为3000而请求来自3001。

**动作：** 发起写入。

**必须断言：** 明确拒绝并提示配置不一致。

**必须排除：** 端口误配置不能靠放宽全部Origin解决。



## T007-C06｜秘密不外泄

**前置：** 查看session响应和日志。

**动作：** 检查所有公开字段。

**必须断言：** 只有随机请求令牌，没有模型Key或笔记。

**必须排除：** 本地保护令牌不应成为读取秘密的快捷入口。
