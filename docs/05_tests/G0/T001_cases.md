# T001 验收用例｜运行时预检与系统边界


本文件是**测试规格**，不是测试结果。实施入口：[T001 运行时预检与系统边界](../../04_tasks/G0/T001_runtime.md)。所属 Gate：G0。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录执行命令、退出码、实际解释器路径与生成文件列表；对文件操作比较目录前后快照。

基线与状态：项目脚本、配置和临时探针文件。

整个用例组不可违反：没有新增模型调用，没有修改真实.data，未改变全局registry或证书配置。

清理方法：关闭本用例启动的进程，只删除本用例临时文件，保留原锁文件用于复核。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T001-C01｜旧运行时

**前置：** 当前 node 为 22 或更低且存在其它 Node 安装。

**动作：** 从项目目录运行 doctor。

**必须断言：** 以明确退出码失败，说明需要受支持主版本并报告实际可执行文件。

**必须排除：** 误用系统旧 Node 导致内置接口缺失。



## T001-C02｜中文路径

**前置：** 项目放在包含中文和空格的目录。

**动作：** 执行临时 SQLite 文件探针。

**必须断言：** 写入和重开结果一致，临时文件被清理。

**必须排除：** 路径拼接错误可能把数据写到另一个位置。



## T001-C03｜目录只读

**前置：** 对测试目录撤销写权限。

**动作：** 运行写权限预检。

**必须断言：** 给出路径不可写错误，不创建半成品数据库。

**必须排除：** 权限错误被当作空数据库会诱导用户重建丢失资料。



## T001-C04｜无互联网

**前置：** 禁用外网但本地 Node 已安装。

**动作：** 只执行环境与数据库检查。

**必须断言：** 本地探针成功，网络检查单独标记未通过。

**必须排除：** 把联网能力和离线笔记能力混成一个失败状态。



## T001-C05｜重复运行

**前置：** 第一次 doctor 已成功且临时目录存在其它文件。

**动作：** 连续执行两次预检。

**必须断言：** 只清理自己创建的文件，不删除用户目录。

**必须排除：** 宽泛清理脚本可能误删不相关资料。



## T001-C06｜版本证据

**前置：** 终端 PATH 中存在两个 Node 版本。

**动作：** 在项目脚本与终端分别输出实际版本。

**必须断言：** 报告可说明二者是否一致并阻止不一致部署。

**必须排除：** 安装了新版本却仍用旧解释器启动应用。
