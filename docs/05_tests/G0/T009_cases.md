# T009 验收用例｜初始迁移与数据库约束


本文件是**测试规格**，不是测试结果。实施入口：[T009 初始迁移与数据库约束](../../04_tasks/G0/T009_migrations.md)。所属 Gate：G0。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：在真实临时文件库执行并检查行数、主外键、版本与事务回滚；关闭重开后再次读取。

基线与状态：目标表、关联表、约束、user_version与连接生命周期。

整个用例组不可违反：没有悬空引用、半事务提交或用户数据库污染；相同请求不造成重复实体。

清理方法：关闭所有测试连接，检查WAL相关文件后仅删除临时目录，不触碰应用真实.data。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T009-C01｜空库初始化

**前置：** 数据库user_version为0。

**动作：** 执行迁移两次。

**必须断言：** 第一次创建结构第二次无操作，版本保持1。

**必须排除：** 重复启动不应重复建表或清空数据。



## T009-C02｜迁移中失败

**前置：** 测试SQL中间插入非法语句。

**动作：** 执行事务迁移。

**必须断言：** 版本不增加，之前语句回滚。

**必须排除：** 半套表会让后续启动进入不可解释状态。



## T009-C03｜高版本数据库

**前置：** user_version设置为99。

**动作：** 启动当前程序。

**必须断言：** 拒绝写入并提示版本不兼容。

**必须排除：** 旧程序不能破坏新格式资料。



## T009-C04｜非法枚举

**前置：** 直接SQL插入未知Item类型。

**动作：** 执行插入。

**必须断言：** CHECK拒绝，即使绕过API也不接受。

**必须排除：** 只依赖UI校验不足以保护底层数据。



## T009-C05｜关系级联

**前置：** 建立两个条目和关联边。

**动作：** 删除一个端点。

**必须断言：** 边被级联删除且外键检查通过。

**必须排除：** 悬空关系会使图渲染失败。



## T009-C06｜幂等唯一

**前置：** 同一capture_request_id插入两条Item。

**动作：** 执行第二次插入。

**必须断言：** 唯一约束拒绝，由服务层映射重放逻辑。

**必须排除：** 并发下只靠前端禁用按钮不可靠。
