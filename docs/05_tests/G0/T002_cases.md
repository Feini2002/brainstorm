## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录执行命令、退出码、实际解释器路径与生成文件列表；对文件操作比较目录前后快照。

基线与状态：项目脚本、配置和临时探针文件。

整个用例组不可违反：没有新增模型调用，没有修改真实.data，未改变全局registry或证书配置。

清理方法：关闭本用例启动的进程，只删除本用例临时文件，保留原锁文件用于复核。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T002-C01｜锁文件恢复

**前置：** 已有一致 package-lock 且删除 node_modules。

**动作：** 执行 npm ci。

**必须断言：** 得到同一依赖树，lockfile 不被无理由重写。

**必须排除：** 重复安装漂移会使后续错误不可复现。



## T002-C02｜配置冲突

**前置：** package.json 与 lockfile 版本不一致。

**动作：** 执行 npm ci。

**必须断言：** 安装明确失败并要求修复差异，不悄悄换最新版。

**必须排除：** 依赖声明与实际构建材料不一致。



## T002-C03｜浏览器未安装

**前置：** Playwright 包已安装但 Chromium 二进制缺失。

**动作：** 运行浏览器测试。

**必须断言：** 报告缺少浏览器及安装命令，不把测试列为通过。

**必须排除：** 只有测试代码没有实际浏览器执行。



## T002-C04｜错误第三方包

**前置：** 实现者尝试安装 npm 上的 sqlite 或 crypto 包。

**动作：** 检查依赖清单与审查脚本。

**必须断言：** 阻止不必要包并继续使用 Node 内置模块。

**必须排除：** 同名包可能带来额外原生构建或供应链风险。



## T002-C05｜断网重装

**前置：** 依赖缓存不完整且网络不可用。

**动作：** 执行 npm ci。

**必须断言：** 保留原锁文件，提示缺少下载材料。

**必须排除：** 为了绕过下载错误改掉已锁定架构。



## T002-C06｜主版本升级

**前置：** 某个子库提示需要更高 React 主版本。

**动作：** 检查 peer dependency 及集成实验。

**必须断言：** 在独立决策中解决兼容，而不是忽略警告强装。

**必须排除：** 运行期 hook 或渲染契约可能与构建期不一致。
