# T011 验收用例｜隔离测试环境与模型替身


本文件是**测试规格**，不是测试结果。实施入口：[T011 隔离测试环境与模型替身](../../04_tasks/G0/T011_test_harness.md)。所属 Gate：G0。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：保存命令、退出码、测试ID、最小输入和预期实际差异，必要时附安全截图及数据库观察。

基线与状态：用例结果、Gate状态、临时数据、报告与明确未执行项。

整个用例组不可违反：测试不触碰用户数据库和可用Key，不自动修改架构来迎合断言。

清理方法：关闭测试服务和浏览器、清理独立目录，保留脱敏失败样本与可重复执行命令。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T011-C01｜误用用户库

**前置：** 未传测试数据目录。

**动作：** 运行集成测试入口。

**必须断言：** 直接失败而不是连接默认.data。

**必须排除：** 自动化测试可能清空真实笔记。



## T011-C02｜超时模拟

**前置：** 替身永远不返回且使用假时钟。

**动作：** 推进超时时间。

**必须断言：** 产生正确终态与错误码，无真实网络。

**必须排除：** 真实等待会使测试慢且不稳定。



## T011-C03｜生产替身泄露

**前置：** 构建production并打开Settings。

**动作：** 检查可选Provider和返回内容。

**必须断言：** 无测试模式入口，不显示固定假结果。

**必须排除：** 把Mock当作完成AI接入是虚假交付。



## T011-C04｜令牌真实保护

**前置：** 浏览器测试未先取session。

**动作：** 调用API。

**必须断言：** 按实际安全规则拒绝。

**必须排除：** 测试绕过保护会掩盖真实产品缺陷。



## T011-C05｜并行隔离

**前置：** 两个测试进程使用不同临时目录。

**动作：** 同时执行写入与清理。

**必须断言：** 互不删除对方文件。

**必须排除：** 全局固定测试路径导致随机失败。



## T011-C06｜无Key报告

**前置：** 执行全部确定性测试。

**动作：** 生成Gate证据。

**必须断言：** 明确真实模型测试未执行。

**必须排除：** 不能把替身通过泛化为外部服务可用。
