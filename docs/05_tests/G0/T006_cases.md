# T006 验收用例｜统一响应、错误与前端请求器


本文件是**测试规格**，不是测试结果。实施入口：[T006 统一响应、错误与前端请求器](../../04_tasks/G0/T006_api_envelope.md)。所属 Gate：G0。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录HTTP状态、响应envelope、requestId、请求次数以及调用前后数据库关键行数量和版本。

基线与状态：请求键、错误码、目标实体及相关datasetRevision。

整个用例组不可违反：拒绝请求不应发生领域写入或外部模型调用；读取接口不应触发修改。

清理方法：清空本用例幂等键和临时数据库，保留脱敏请求响应以便复现。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T006-C01｜非JSON响应

**前置：** 开发代理返回HTML错误页。

**动作：** 通过apiClient读取接口。

**必须断言：** 得到可读协议错误而不是JSON解析堆栈。

**必须排除：** 页面可能把HTML正文误当成业务结果。



## T006-C02｜字段校验

**前置：** 向条目接口提交超长title。

**动作：** 观察HTTP和错误体。

**必须断言：** 状态400或422与稳定错误码一致，定位title字段。

**必须排除：** 每页单独解析字符串错误会变得脆弱。



## T006-C03｜服务器异常

**前置：** Repository抛出带绝对路径的错误。

**动作：** 调用接口。

**必须断言：** 浏览器只见安全错误，详细信息受控记录。

**必须排除：** 错误堆栈可能泄露路径和配置内容。



## T006-C04｜网络断开

**前置：** POST已发出但响应断开。

**动作：** 观察apiClient行为。

**必须断言：** 不自动再发付费请求，保留幂等键与未知完成提示。

**必须排除：** 自动重试可能导致重复保存或双重费用。



## T006-C05｜缓存回放

**前置：** 用户修改条目后立即读取。

**动作：** 检查响应头和实际数据。

**必须断言：** 返回新revision且响应不可共享缓存。

**必须排除：** 旧缓存会让界面误认为保存没有生效。



## T006-C06｜统一契约

**前置：** 分别调用三个不同业务接口。

**动作：** 比较成功与失败结构。

**必须断言：** 调用方能用同一解析器处理。

**必须排除：** 不统一会使后续组件复制大量容错分支。
