本文件是**测试规格**，不是测试结果。实施入口：[T004 启动脚本、回环监听与退出](../../04_tasks/G0/T004_startup_scripts.md)。所属 Gate：G0。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录执行命令、退出码、实际解释器路径与生成文件列表；对文件操作比较目录前后快照。

基线与状态：项目脚本、配置和临时探针文件。

整个用例组不可违反：没有新增模型调用，没有修改真实.data，未改变全局registry或证书配置。

清理方法：关闭本用例启动的进程，只删除本用例临时文件，保留原锁文件用于复核。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T004-C01｜外部接口

**前置：** 应用正常启动。

**动作：** 查看监听地址并从另一设备尝试连接。

**必须断言：** 只绑定回环，局域网不能直接访问。

**必须排除：** 没有账户体系的本机应用不应暴露公网或局域网。



## T004-C02｜端口占用

**前置：** 3000 已被另一个进程占用。

**动作：** 运行启动脚本。

**必须断言：** 明确报错并退出，不静默切到3001。

**必须排除：** 地址变化会破坏来源校验和用户书签。



## T004-C03｜Windows启动

**前置：** PowerShell 中使用默认命令。

**动作：** 运行 dev 与 production start。

**必须断言：** 不需要 POSIX 专用环境赋值语法。

**必须排除：** 用户复制命令却无法在自己的系统执行。



## T004-C04｜无生产构建

**前置：** 删除构建输出后执行 start。

**动作：** 运行生产启动。

**必须断言：** 提示先 build，而非退回开发模式。

**必须排除：** 不能把开发服务当成稳定发布运行方式。



## T004-C05｜退出进程

**前置：** 应用正在空闲且数据库已初始化。

**动作：** 按 Ctrl+C 并重新启动。

**必须断言：** 端口释放、数据保留、进程退出码合理。

**必须排除：** 孤儿进程会造成锁冲突和误判数据丢失。



## T004-C06｜检查脚本

**前置：** 故意引入 lint 错误但类型仍通过。

**动作：** 执行完整检查。

**必须断言：** lint 阶段独立失败并阻止 Gate。

**必须排除：** 只用 build 成功掩盖质量门禁缺失。
