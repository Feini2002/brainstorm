# T044 验收用例｜领域图到React Flow适配


本文件是**测试规格**，不是测试结果。实施入口：[T044 领域图到React Flow适配](../../04_tasks/G3/T044_graph_adapter.md)。所属 Gate：G3。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录节点边ID、数量、坐标、viewport与选择状态，检查对应Item/Relation/View版本是否按职责变化。

基线与状态：GraphData、布局位置、筛选条件、关系状态与来源版本。

整个用例组不可违反：只有明确领域动作可以写知识；图形生命周期没有重复监听或持续外部网络。

清理方法：卸载画布并断言实例清理，重开已存View核对位置；不以重置所有知识修复图形问题。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T044-C01｜稳定ID

**前置：** 对同一GraphData连续转换两次。

**动作：** 比较nodes和edges。

**必须断言：** ID不变且选择状态可复用。

**必须排除：** 每次随机ID会导致闪烁和位置丢失。



## T044-C02｜来源回跳

**前置：** 点击由适配器创建的node。

**动作：** 打开详情。

**必须断言：** 对应真实Item ID。

**必须排除：** 展示对象必须保留来源链。



## T044-C03｜对称边

**前置：** similar_to关系规范化端点。

**动作：** 渲染标签。

**必须断言：** 表达相似而非因果方向。

**必须排除：** 存储排序不代表知识方向。



## T044-C04｜建议样式

**前置：** suggested与accepted混合。

**动作：** 查看图及可访问文本。

**必须断言：** 两者不仅颜色不同，状态也可读。

**必须排除：** 色觉差异不能使审核信息消失。



## T044-C05｜引用污染

**前置：** 冻结输入GraphData后转换并拖动。

**动作：** 检查原对象。

**必须断言：** 没有被修改。

**必须排除：** UI状态不能写进领域数据。



## T044-C06｜敏感最小化

**前置：** 检查node.data内容。

**动作：** 打开开发工具。

**必须断言：** 没有Key和不必要的大型正文。

**必须排除：** 图节点缓存不应复制整库信息。
