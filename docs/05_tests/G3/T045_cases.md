# T045 验收用例｜关系画布、自定义节点与容器


本文件是**测试规格**，不是测试结果。实施入口：[T045 关系画布、自定义节点与容器](../../04_tasks/G3/T045_reactflow_canvas.md)。所属 Gate：G3。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录节点边ID、数量、坐标、viewport与选择状态，检查对应Item/Relation/View版本是否按职责变化。

基线与状态：GraphData、布局位置、筛选条件、关系状态与来源版本。

整个用例组不可违反：只有明确领域动作可以写知识；图形生命周期没有重复监听或持续外部网络。

清理方法：卸载画布并断言实例清理，重开已存View核对位置；不以重置所有知识修复图形问题。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T045-C01｜零尺寸

**前置：** 父容器没有显式高度。

**动作：** 集成检查。

**必须断言：** 修复布局而不是给空图伪数据。

**必须排除：** React Flow空白常是容器而非数据问题。



## T045-C02｜Provider缺失

**前置：** 测试组件调用图hook但无Provider。

**动作：** 运行组件测试。

**必须断言：** 明确定位上下文错误。

**必须排除：** 随意移动Provider会制造难复现状态。



## T045-C03｜重复挂载

**前置：** 开发模式挂载清理再挂载。

**动作：** 操作图。

**必须断言：** 只有一个实例和一组事件监听。

**必须排除：** 副作用未清理会导致重复响应。



## T045-C04｜长标题

**前置：** 节点标题达到一百码点。

**动作：** 渲染并拖动。

**必须断言：** 卡片尺寸稳定，全文仍可查看。

**必须排除：** 尺寸变化会使布局重叠。



## T045-C05｜键盘删除

**前置：** 选中节点按Delete。

**动作：** 观察数据库。

**必须断言：** 不删除笔记，需明确产品确认流程。

**必须排除：** 画布默认操作不能成为危险快捷键。



## T045-C06｜加载失败

**前置：** 模拟图形chunk加载失败。

**动作：** 进入Graph。

**必须断言：** 显示局部重试，Inbox仍可用。

**必须排除：** 第三方组件不能成为全站单点崩溃。
