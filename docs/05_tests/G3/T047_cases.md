# T047 验收用例｜图位置保存与布局版本冲突


本文件是**测试规格**，不是测试结果。实施入口：[T047 图位置保存与布局版本冲突](../../04_tasks/G3/T047_layout_persistence.md)。所属 Gate：G3。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录节点边ID、数量、坐标、viewport与选择状态，检查对应Item/Relation/View版本是否按职责变化。

基线与状态：GraphData、布局位置、筛选条件、关系状态与来源版本。

整个用例组不可违反：只有明确领域动作可以写知识；图形生命周期没有重复监听或持续外部网络。

清理方法：卸载画布并断言实例清理，重开已存View核对位置；不以重置所有知识修复图形问题。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T047-C01｜刷新保持

**前置：** 拖动三个节点并保存。

**动作：** 刷新浏览器。

**必须断言：** 位置接近保存值且来源ID一致。

**必须排除：** 布局持久化是独立产品价值。



## T047-C02｜每帧写入

**前置：** 持续拖动十秒。

**动作：** 统计API调用。

**必须断言：** 只在受控时机有限提交。

**必须排除：** 高频SQLite写入会让本机交互变慢。



## T047-C03｜双窗口布局

**前置：** 两窗口读取同View revision。

**动作：** 分别拖动保存。

**必须断言：** 后者冲突而不是静默覆盖。

**必须排除：** 视图状态也需要并发语义。



## T047-C04｜删除节点

**前置：** View位置含已删Item。

**动作：** 重新打开。

**必须断言：** 清理或忽略该位置，不重建知识。

**必须排除：** presentation不能反向复活数据。



## T047-C05｜恶意坐标

**前置：** 提交Infinity或极端坐标。

**动作：** 保存layout。

**必须断言：** 拒绝非法数据。

**必须排除：** 坏坐标会造成无法找回画布内容。



## T047-C06｜初始化竞态

**前置：** 已存布局读取较慢。

**动作：** 页面首次装载。

**必须断言：** 不先自动布局后覆盖保存位置。

**必须排除：** 数据与布局到达顺序需要协调。
