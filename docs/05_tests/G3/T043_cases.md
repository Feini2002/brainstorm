# T043 验收用例｜图谱读取接口与子图范围


本文件是**测试规格**，不是测试结果。实施入口：[T043 图谱读取接口与子图范围](../../04_tasks/G3/T043_graph_query.md)。所属 Gate：G3。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录节点边ID、数量、坐标、viewport与选择状态，检查对应Item/Relation/View版本是否按职责变化。

基线与状态：GraphData、布局位置、筛选条件、关系状态与来源版本。

整个用例组不可违反：只有明确领域动作可以写知识；图形生命周期没有重复监听或持续外部网络。

清理方法：卸载画布并断言实例清理，重开已存View核对位置；不以重置所有知识修复图形问题。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T043-C01｜孤立知识

**前置：** 库有十条Item但零关系。

**动作：** 读取图谱。

**必须断言：** 返回十节点零边并正常显示。

**必须排除：** 不能把没有关系当作图加载失败。



## T043-C02｜拒绝关系

**前置：** 存在rejected边。

**动作：** 默认读取图谱。

**必须断言：** 不包含该边但节点可保留。

**必须排除：** 用户拒绝必须在视图上生效。



## T043-C03｜端点过滤

**前置：** 标签筛选只保留边的一端。

**动作：** 查询子图。

**必须断言：** 该边不返回。

**必须排除：** 悬空边可能触发渲染错误或误导来源。



## T043-C04｜人工评分

**前置：** 人工边score为null且阈值0.8。

**动作：** 查询。

**必须断言：** 人工accepted边不被评分过滤误删。

**必须排除：** null不是零分。



## T043-C05｜超限提示

**前置：** 匹配节点超过二百。

**动作：** 读取图谱。

**必须断言：** 提示范围限制并建议筛选。

**必须排除：** 用户应知道看到的不是全部知识。



## T043-C06｜过期边

**前置：** 修改关系一端原文。

**动作：** 读取图谱。

**必须断言：** 默认不参与当前有效关系，可切换查看旧边。

**必须排除：** 旧语义不能无提示继续投影。
