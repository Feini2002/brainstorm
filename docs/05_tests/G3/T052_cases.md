# T052 验收用例｜关系图集成验收与组件替换边界


本文件是**测试规格**，不是测试结果。实施入口：[T052 关系图集成验收与组件替换边界](../../04_tasks/G3/T052_graph_acceptance.md)。所属 Gate：G3。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：保存命令、退出码、测试ID、最小输入和预期实际差异，必要时附安全截图及数据库观察。

基线与状态：用例结果、Gate状态、临时数据、报告与明确未执行项。

整个用例组不可违反：测试不触碰用户数据库和可用Key，不自动修改架构来迎合断言。

清理方法：关闭测试服务和浏览器、清理独立目录，保留脱敏失败样本与可重复执行命令。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T052-C01｜真实数据闭环

**前置：** 从Inbox创建并建立关系。

**动作：** 进入Graph布局保存刷新。

**必须断言：** 图与Library同源且位置恢复。

**必须排除：** 不能拿静态图冒充系统集成。



## T052-C02｜审核联动

**前置：** Graph中拒绝建议边。

**动作：** 回到Library关系详情。

**必须断言：** 审核结果一致且未再生。

**必须排除：** 跨页面要共享真正状态。



## T052-C03｜布局不写知识

**前置：** 记录Item版本后拖动图。

**动作：** 比较数据库。

**必须断言：** Item版本不变，仅View版本改变。

**必须排除：** 展示行为不能产生语义修改。



## T052-C04｜异常图集

**前置：** 载入环孤点多分量。

**动作：** 分别自动布局。

**必须断言：** 正常或有明确降级，无页面崩溃。

**必须排除：** 真实知识关系不总是理想树。



## T052-C05｜重启恢复

**前置：** 图布局保存完毕。

**动作：** 停止并重新启动。

**必须断言：** 同View可恢复位置与范围。

**必须排除：** 仅浏览器内存状态不算持久化。



## T052-C06｜替换审查

**前置：** 检查Graph组件的数据库依赖。

**动作：** 静态扫描。

**必须断言：** 无直接SQL与秘密模块导入。

**必须排除：** Renderer应保持可替换。
