# T049 验收用例｜节点详情与关系审核交互


本文件是**测试规格**，不是测试结果。实施入口：[T049 节点详情与关系审核交互](../../04_tasks/G3/T049_graph_interactions.md)。所属 Gate：G3。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录节点边ID、数量、坐标、viewport与选择状态，检查对应Item/Relation/View版本是否按职责变化。

基线与状态：GraphData、布局位置、筛选条件、关系状态与来源版本。

整个用例组不可违反：只有明确领域动作可以写知识；图形生命周期没有重复监听或持续外部网络。

清理方法：卸载画布并断言实例清理，重开已存View核对位置；不以重置所有知识修复图形问题。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T049-C01｜节点一致

**前置：** 从Library与Graph打开同一ID。

**动作：** 编辑标题。

**必须断言：** 两处后续读取一致。

**必须排除：** 重复详情实现容易出现字段遗漏。



## T049-C02｜证据查看

**前置：** 选中AI建议边。

**动作：** 展开检查面板。

**必须断言：** 能看到对应原文摘录与版本。

**必须排除：** 没有依据的图只是一张装饰图。



## T049-C03｜拖动误触

**前置：** 拖动卡片改变位置。

**动作：** 释放鼠标。

**必须断言：** 不意外打开编辑或删除对话框。

**必须排除：** 交互冲突会使画布难用。



## T049-C04｜审核刷新

**前置：** 在Graph拒绝一条建议。

**动作：** 查看当前子图。

**必须断言：** 该边按过滤规则消失，其它位置保留。

**必须排除：** 整图重建会破坏用户上下文。



## T049-C05｜关系冲突

**前置：** 边在另一窗口被审核。

**动作：** 提交旧revision。

**必须断言：** 显示冲突并重新读取。

**必须排除：** 不能以乐观UI掩盖未保存决定。



## T049-C06｜密集边

**前置：** 多个关系标签聚集。

**动作：** 选择其中一条。

**必须断言：** 能在检查面板看全文，图上仍可辨认。

**必须排除：** 把全部理由铺在画布上会不可读。
