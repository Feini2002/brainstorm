# T050 验收用例｜大图降级、无障碍与可读性


本文件是**测试规格**，不是测试结果。实施入口：[T050 大图降级、无障碍与可读性](../../04_tasks/G3/T050_graph_readability.md)。所属 Gate：G3。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录节点边ID、数量、坐标、viewport与选择状态，检查对应Item/Relation/View版本是否按职责变化。

基线与状态：GraphData、布局位置、筛选条件、关系状态与来源版本。

整个用例组不可违反：只有明确领域动作可以写知识；图形生命周期没有重复监听或持续外部网络。

清理方法：卸载画布并断言实例清理，重开已存View核对位置；不以重置所有知识修复图形问题。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T050-C01｜二百节点

**前置：** 生成接近预算的测试图。

**动作：** 打开拖动缩放。

**必须断言：** 记录实际延迟，核心动作仍可完成。

**必须排除：** 不能以十节点演示推断规模能力。



## T050-C02｜文本替代

**前置：** 用户不用图形画布。

**动作：** 打开关系列表。

**必须断言：** 能检查同样关系和来源。

**必须排除：** 关键功能不应只存在于视觉连线。



## T050-C03｜色觉差异

**前置：** 忽略所有颜色信息。

**动作：** 区分建议与已确认边。

**必须断言：** 文字线型仍表达状态。

**必须排除：** 只靠颜色不满足基本可访问性。



## T050-C04｜超限全库

**前置：** 知识量远超画布预算。

**动作：** 进入Graph。

**必须断言：** 说明当前范围且保留检索入口。

**必须排除：** 受限视图不代表数据丢失。



## T050-C05｜稀疏空图

**前置：** 只有一个Item。

**动作：** 查看Graph。

**必须断言：** 显示可读节点与下一步建议。

**必须排除：** 空关系不能被当成失败。



## T050-C06｜图例语义

**前置：** 存在causes与related_to。

**动作：** 查看图例。

**必须断言：** 两者解释不同，不都叫关联。

**必须排除：** 类型差异影响用户理解。
