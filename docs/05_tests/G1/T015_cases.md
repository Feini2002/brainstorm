# T015 验收用例｜收件箱时间线与知识卡片


本文件是**测试规格**，不是测试结果。实施入口：[T015 收件箱时间线与知识卡片](../../04_tasks/G1/T015_timeline_cards.md)。所属 Gate：G1。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：用可访问角色和稳定测试标识定位控件，记录用户动作前后的DOM、请求参数和服务端读取结果。

基线与状态：页面草稿、选中ID、按钮状态、服务器返回的版本。

整个用例组不可违反：没有由导航或重渲染触发的额外付费调用，没有把失败提示当成保存成功。

清理方法：关闭抽屉并清理组件，重新读取服务端状态；测试草稿不进入用户浏览器长期存储。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T015-C01｜未整理卡片

**前置：** 条目只有rawText且title为空。

**动作：** 打开Inbox。

**必须断言：** 显示可辨认原文预览与未整理状态。

**必须排除：** 空标题不能使记录看起来不存在。



## T015-C02｜跨午夜

**前置：** 记录UTC时间在本地午夜附近。

**动作：** 切换浏览器时区查看分组。

**必须断言：** 绝对时间不变，分组按本地规则合理变化。

**必须排除：** 存储时区和展示时区混用会错排日期。



## T015-C03｜同名记录

**前置：** 两条不同ID但相同title。

**动作：** 编辑其中一条。

**必须断言：** 只更新对应卡片，组件key不冲突。

**必须排除：** 使用标题做key会造成内容串位。



## T015-C04｜保存回显

**前置：** 刚创建成功服务端返回条目。

**动作：** 刷新当前列表。

**必须断言：** 不出现临时条目与真实条目双份。

**必须排除：** 乐观更新合并错误导致视觉重复。



## T015-C05｜失败可读

**前置：** AI整理失败且原文已保存。

**动作：** 查看卡片并打开。

**必须断言：** 原文仍在且有重试入口。

**必须排除：** 把失败当成无数据会隐藏用户材料。



## T015-C06｜长文本

**前置：** 原文有一万字。

**动作：** 显示卡片。

**必须断言：** 预览受限但详情完整，不在卡片渲染全部内容。

**必须排除：** 大型文本列表会造成初始页面卡顿。
