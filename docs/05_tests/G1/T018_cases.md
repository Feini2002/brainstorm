# T018 验收用例｜详情抽屉、原文和来源回溯


本文件是**测试规格**，不是测试结果。实施入口：[T018 详情抽屉、原文和来源回溯](../../04_tasks/G1/T018_item_details.md)。所属 Gate：G1。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：用可访问角色和稳定测试标识定位控件，记录用户动作前后的DOM、请求参数和服务端读取结果。

基线与状态：页面草稿、选中ID、按钮状态、服务器返回的版本。

整个用例组不可违反：没有由导航或重渲染触发的额外付费调用，没有把失败提示当成保存成功。

清理方法：关闭抽屉并清理组件，重新读取服务端状态；测试草稿不进入用户浏览器长期存储。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T018-C01｜初始原文

**前置：** 用户修改过rawText。

**动作：** 打开详情并展开来源。

**必须断言：** 同时看到初始capturedText和当前rawText及版本。

**必须排除：** 无法区分最初材料与后期修订会失去可追溯性。



## T018-C02｜HTML材料

**前置：** 原文是script和img标记。

**动作：** 打开详情。

**必须断言：** 显示字面文本，没有执行或外部请求。

**必须排除：** 笔记内容不能成为同源脚本入口。



## T018-C03｜恶意来源

**前置：** sourceRef填javascript协议。

**动作：** 点击来源位置。

**必须断言：** 不生成可执行链接，仍可显示安全文本。

**必须排除：** 手动输入来源也不能绕过链接协议规则。



## T018-C04｜键盘抽屉

**前置：** 从卡片按钮打开详情。

**动作：** 按Tab与Escape。

**必须断言：** 焦点被正确管理并回到卡片。

**必须排除：** 无焦点管理会让页面操作迷失。



## T018-C05｜删除竞态

**前置：** 抽屉打开时另一标签页删除条目。

**动作：** 刷新详情。

**必须断言：** 显示不存在并允许关闭，没有无限重试。

**必须排除：** 读取404不能被误判为临时网络失败。



## T018-C06｜图谱回溯

**前置：** 从关系图节点打开详情。

**动作：** 检查Item ID与原文。

**必须断言：** 与Library同一条记录一致。

**必须排除：** 视图中的文字不能成为断开的副本。
