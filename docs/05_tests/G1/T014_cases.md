# T014 验收用例｜保存接口与采集幂等


本文件是**测试规格**，不是测试结果。实施入口：[T014 保存接口与采集幂等](../../04_tasks/G1/T014_capture_api.md)。所属 Gate：G1。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：记录HTTP状态、响应envelope、requestId、请求次数以及调用前后数据库关键行数量和版本。

基线与状态：请求键、错误码、目标实体及相关datasetRevision。

整个用例组不可违反：拒绝请求不应发生领域写入或外部模型调用；读取接口不应触发修改。

清理方法：清空本用例幂等键和临时数据库，保留脱敏请求响应以便复现。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T014-C01｜双击提交

**前置：** 两次请求使用同一键和内容。

**动作：** 并发POST创建。

**必须断言：** 数据库只有一个Item，两个响应引用同一ID。

**必须排除：** 前端禁用按钮无法覆盖所有并发情况。



## T014-C02｜响应丢失

**前置：** 第一次事务提交但响应被丢弃。

**动作：** 以同一键重新POST。

**必须断言：** 返回已有条目，不再次增加datasetRevision。

**必须排除：** 网络未知完成状态容易产生重复记录。



## T014-C03｜键冲突

**前置：** 同一请求键先保存A后保存B。

**动作：** 第二次POST不同内容。

**必须断言：** 409且A不改变，B仍保留在前端草稿。

**必须排除：** 错误重用请求键不能覆盖既有知识。



## T014-C04｜故意重复

**前置：** 用户两次独立采集相同一句话。

**动作：** 用两个新请求键提交。

**必须断言：** 生成两个ID并允许来源不同。

**必须排除：** 内容哈希不能作为唯一主键。



## T014-C05｜事务失败

**前置：** 测试中标签创建或版本更新抛错。

**动作：** 执行创建服务。

**必须断言：** 整次回滚，没有半成功记录。

**必须排除：** 保存成功提示必须对应完整提交。



## T014-C06｜系统字段注入

**前置：** 请求体带id、revision、capturedText等额外字段。

**动作：** 调用创建接口。

**必须断言：** 严格schema拒绝或忽略未授权字段并有明确规范。

**必须排除：** 用户输入不能伪造身份与版本。
