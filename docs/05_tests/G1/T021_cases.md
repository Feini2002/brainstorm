# T021 验收用例｜跨视图材料选择与数量预算


本文件是**测试规格**，不是测试结果。实施入口：[T021 跨视图材料选择与数量预算](../../04_tasks/G1/T021_selection.md)。所属 Gate：G1。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：用可访问角色和稳定测试标识定位控件，记录用户动作前后的DOM、请求参数和服务端读取结果。

基线与状态：页面草稿、选中ID、按钮状态、服务器返回的版本。

整个用例组不可违反：没有由导航或重渲染触发的额外付费调用，没有把失败提示当成保存成功。

清理方法：关闭抽屉并清理组件，重新读取服务端状态；测试草稿不进入用户浏览器长期存储。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T021-C01｜重复勾选

**前置：** 同一Item通过多个入口被选中。

**动作：** 打开选择托盘。

**必须断言：** 只计算一次并使用同一ID。

**必须排除：** 重复来源会浪费上下文和生成重复节点。



## T021-C02｜超过四十

**前置：** 尝试选择四十一条来源。

**动作：** 点击生成。

**必须断言：** 被阻止并说明数量限制。

**必须排除：** 静默截断会让用户误以为全部已分析。



## T021-C03｜隐藏选中

**前置：** 选了五条再切换筛选。

**动作：** 查看托盘。

**必须断言：** 明确显示仍选中的隐藏条目数量。

**必须排除：** 不可见选择可能导致意外发送材料。



## T021-C04｜已删来源

**前置：** 选择后另一操作删除其中一条。

**动作：** 提交生成。

**必须断言：** 服务端拒绝或要求重新选择，不默默跳过。

**必须排除：** 生成来源不完整会损害解释可信度。



## T021-C05｜标签快照

**前置：** 选择某标签后新增同标签记录。

**动作：** 点击生成。

**必须断言：** 以点击时解析结果形成版本快照。

**必须排除：** 动态查询与实际发送内容可能不一致。



## T021-C06｜无模型副作用

**前置：** 只从Library跳到Mindmap。

**动作：** 观察网络。

**必须断言：** 没有外部模型请求。

**必须排除：** 导航不应自动产生费用。
