# T024 验收用例｜无Key与断网可用路径


本文件是**测试规格**，不是测试结果。实施入口：[T024 无Key与断网可用路径](../../04_tasks/G1/T024_offline_crud.md)。所属 Gate：G1。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：从用户入口记录动作、网络、实体版本和重启后结果，分别检查本机与外网流量。

基线与状态：整条旅程中的Item、Relation、View、Run与页面状态。

整个用例组不可违反：本地操作不调用模型，AI失败不阻断已有知识读取和下一次采集。

清理方法：关闭隔离应用实例并清理测试数据，保留旅程证据和具体失败步骤。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T024-C01｜无Key创建

**前置：** settings为空。

**动作：** 创建编辑搜索三条笔记。

**必须断言：** 全部成功且无模型请求。

**必须排除：** 最基础记录流程不应依赖付费服务。



## T024-C02｜外网断开

**前置：** 本机服务在线外部域名不可达。

**动作：** 浏览Library与手动关系。

**必须断言：** 功能正常，AI操作单独失败。

**必须排除：** 全局网络状态不能封锁本地数据库。



## T024-C03｜已存脑图

**前置：** 已有有效View且外网不可用。

**动作：** 打开并展开脑图。

**必须断言：** 使用本地资源渲染，没有CDN拉取。

**必须排除：** 隐式外部插件会破坏离线承诺。



## T024-C04｜服务关闭

**前置：** Node进程已停止。

**动作：** 访问页面。

**必须断言：** 浏览器连接失败且文档说明需先启动。

**必须排除：** 本地优先不等同于完整PWA后台服务。



## T024-C05｜AI失败后继续

**前置：** 整理请求网络超时。

**动作：** 立即保存另一条笔记。

**必须断言：** 保存成功，不受先前错误阻断。

**必须排除：** 全站错误锁会把非AI功能一起瘫痪。



## T024-C06｜资源检查

**前置：** 阻断远程字体和图标域名。

**动作：** 浏览六页。

**必须断言：** 文字和关键控件仍可用。

**必须排除：** 视觉资源不该成为功能依赖。
