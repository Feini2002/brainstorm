# T054 验收用例｜来源选择快照、版本和哈希


本文件是**测试规格**，不是测试结果。实施入口：[T054 来源选择快照、版本和哈希](../../04_tasks/G4/T054_source_snapshot.md)。所属 Gate：G4。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：比对canonical JSON、来源ID与版本、编译哈希、DOM实例和外部请求；检查旧View是否被保留。

基线与状态：View内容、sourceSnapshot、编译版本、渲染token与过期信息。

整个用例组不可违反：生成失败不破坏旧图，浏览或重试本地渲染不重新计费，来源不被复制成独立知识。

清理方法：撤销ObjectURL并清理Renderer实例，保留安全canonical样本用于复现；删除测试View不删知识。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T054-C01｜顺序无关

**前置：** 相同ID集合以不同顺序提交。

**动作：** 计算inputHash。

**必须断言：** 同一版本下哈希相同。

**必须排除：** 数组顺序不应制造无意义重复任务。



## T054-C02｜正文不可信

**前置：** 浏览器伪造Item摘要。

**动作：** 生成服务读取来源。

**必须断言：** 以数据库版本为准。

**必须排除：** 前端草稿不是已确认知识来源。



## T054-C03｜生成中变化

**前置：** 模型处理时修改一个来源。

**动作：** 最终保存。

**必须断言：** 检测冲突，不混合版本。

**必须排除：** 图的依据必须是同一时点快照。



## T054-C04｜标签新成员

**前置：** 旧图按标签生成后新增同标签条目。

**动作：** 读取旧图。

**必须断言：** 提示选择集合变化但旧图不变。

**必须排除：** 动态筛选不能悄悄改写历史视图。



## T054-C05｜关系变化

**前置：** 来源关系被拒绝或修改。

**动作：** 读取依赖该关系的图。

**必须断言：** 显示过期依据。

**必须排除：** 只比较Item版本会遗漏关系语义变化。



## T054-C06｜预算透明

**前置：** 用户选择超过限制。

**动作：** 提交生成。

**必须断言：** 明确指出需要减少来源数量。

**必须排除：** 隐式截断让用户误以为全部材料已纳入。
