# T053 验收用例｜保存视图的公共API与类型契约


本文件是**测试规格**，不是测试结果。实施入口：[T053 保存视图的公共API与类型契约](../../04_tasks/G4/T053_view_repository.md)。所属 Gate：G4。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：比对canonical JSON、来源ID与版本、编译哈希、DOM实例和外部请求；检查旧View是否被保留。

基线与状态：View内容、sourceSnapshot、编译版本、渲染token与过期信息。

整个用例组不可违反：生成失败不破坏旧图，浏览或重试本地渲染不重新计费，来源不被复制成独立知识。

清理方法：撤销ObjectURL并清理Renderer实例，保留安全canonical样本用于复现；删除测试View不删知识。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T053-C01｜不同类型

**前置：** 提交mindmap kind但flow内容。

**动作：** 保存View。

**必须断言：** 判别schema拒绝。

**必须排除：** 任意JSON会把错误推迟到浏览器。



## T053-C02｜视图删除

**前置：** View引用三条Item。

**动作：** 删除该View。

**必须断言：** 三条知识和关系仍存在。

**必须排除：** 观察方式不拥有知识实体生命周期。



## T053-C03｜重名视图

**前置：** 保存两个同名脑图。

**动作：** 读取列表。

**必须断言：** 不同ID均可访问。

**必须排除：** 名称不能承担身份职责。



## T053-C04｜列表轻量

**前置：** 保存多个大型图。

**动作：** 查询View列表。

**必须断言：** 只返回摘要与必要元数据。

**必须排除：** 历史页不应一次载入全部内容。



## T053-C05｜再生成保留

**前置：** 旧View已存在。

**动作：** 点击重新生成。

**必须断言：** 创建新View而旧View不被覆盖。

**必须排除：** 用户需要对比生成前后的组织方式。



## T053-C06｜来源缺失

**前置：** 引用Item已经删除。

**动作：** 读View详情。

**必须断言：** 返回missingSources而非整个404。

**必须排除：** View自身仍是可读历史产物。
