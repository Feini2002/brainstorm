# T057 验收用例｜Markmap挂载、净化与本地资源


本文件是**测试规格**，不是测试结果。实施入口：[T057 Markmap挂载、净化与本地资源](../../04_tasks/G4/T057_markmap_renderer.md)。所属 Gate：G4。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：比对canonical JSON、来源ID与版本、编译哈希、DOM实例和外部请求；检查旧View是否被保留。

基线与状态：View内容、sourceSnapshot、编译版本、渲染token与过期信息。

整个用例组不可违反：生成失败不破坏旧图，浏览或重试本地渲染不重新计费，来源不被复制成独立知识。

清理方法：撤销ObjectURL并清理Renderer实例，保留安全canonical样本用于复现；删除测试View不删知识。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T057-C01｜首次显示

**前置：** 合法树已编译Markdown。

**动作：** 打开Mindmap。

**必须断言：** 出现可缩放折叠SVG与正确中文。

**必须排除：** 有源码文本不等于已完成可视化。



## T057-C02｜重复挂载

**前置：** React开发模式额外挂载清理。

**动作：** 切换页面多次。

**必须断言：** 无重复SVG和事件。

**必须排除：** 未清理实例会持续占用内存。



## T057-C03｜外部资源

**前置：** 标签试图嵌入远端图片。

**动作：** 渲染并监听网络。

**必须断言：** 没有外部请求。

**必须排除：** 已保存视图应离线可读。



## T057-C04｜缩放保持

**前置：** 用户手动放大脑图。

**动作：** 编辑旁侧非图字段。

**必须断言：** 不被无关render强制重置视口。

**必须排除：** 自动fit不能覆盖所有用户交互。



## T057-C05｜容器变化

**前置：** 侧栏开合改变宽度。

**动作：** 调整布局。

**必须断言：** 脑图仍可见，尺寸观察无循环。

**必须排除：** Resize触发链可能造成抖动。



## T057-C06｜渲染失败

**前置：** 测试注入无法处理的结构版本。

**动作：** 打开View。

**必须断言：** 显示安全大纲与可读错误。

**必须排除：** 图形失败不能丢失来源访问。
