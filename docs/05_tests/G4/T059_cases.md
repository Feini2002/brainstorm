# T059 验收用例｜视图过期、再生成与历史保留


本文件是**测试规格**，不是测试结果。实施入口：[T059 视图过期、再生成与历史保留](../../04_tasks/G4/T059_view_regeneration.md)。所属 Gate：G4。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：比对canonical JSON、来源ID与版本、编译哈希、DOM实例和外部请求；检查旧View是否被保留。

基线与状态：View内容、sourceSnapshot、编译版本、渲染token与过期信息。

整个用例组不可违反：生成失败不破坏旧图，浏览或重试本地渲染不重新计费，来源不被复制成独立知识。

清理方法：撤销ObjectURL并清理Renderer实例，保留安全canonical样本用于复现；删除测试View不删知识。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T059-C01｜原文变化

**前置：** 保存脑图后编辑来源。

**动作：** 重新打开脑图。

**必须断言：** 显示过期原因但图内容未被暗改。

**必须排除：** 历史视图应保持生成时语义。



## T059-C02｜再生成成功

**前置：** 旧View存在且材料更新。

**动作：** 点击重新生成。

**必须断言：** 产生新ID，旧View仍可访问。

**必须排除：** 覆盖旧图会失去对比依据。



## T059-C03｜再生成失败

**前置：** 新请求返回错误。

**动作：** 查看旧图。

**必须断言：** 保持原内容与时间。

**必须排除：** 错误不应破坏已有成果。



## T059-C04｜标签成员变化

**前置：** 标签下新增来源。

**动作：** 重新生成确认。

**必须断言：** 显示新的选择数量供确认。

**必须排除：** 用户应知道将发送哪些材料。



## T059-C05｜只改名称

**前置：** 用户重命名View。

**动作：** 保存。

**必须断言：** 不调用模型，不更新generatedAt。

**必须排除：** 观察方式的标签不等于重新分析。



## T059-C06｜来源全删

**前置：** 所有引用Item已删除。

**动作：** 尝试重新生成。

**必须断言：** 阻止无材料请求，旧图仍可读。

**必须排除：** 不能让模型凭记忆编造来源。
