# T060 验收用例｜脑图Markdown与JSON导出


本文件是**测试规格**，不是测试结果。实施入口：[T060 脑图Markdown与JSON导出](../../04_tasks/G4/T060_mindmap_export.md)。所属 Gate：G4。规范字段和限制见 [契约索引](../../03_contracts/00_contract_index.md)。

## 公共测试装置

用例使用隔离数据与不可用的测试秘密。任何真实连接验证都应单独记录，并由用户在自己的设置页配置。自动化测试不得连接默认用户数据库。外部依赖替身不得绕过业务校验和事务。

观察方法：将下载内容重新解析，检查字段集合和引用闭包，再在第二个临时库恢复并对比领域语义。

基线与状态：schemaVersion、记录数量、ID映射、秘密排除与恢复前后数据库。

整个用例组不可违反：验证不写入，失败不留半包数据，下载和恢复不触发模型调用。

清理方法：删除测试下载与临时恢复库，保留脱敏校验报告；真实备份原件不能被测试覆盖。每个场景必须从明确基线开始，不依赖上一场景残留的缓存或运行记录。幂等测试要明确有意复用的键，非幂等测试不得误复用。

实际执行结果应追加到 implementation/progress/evidence/ 下，不直接把规格的预期句改成已完成结论。浏览器截图、数据库断言、外部请求次数分别证明不同事情，不能相互替代。

## T060-C01｜中文编码

**前置：** 脑图标签全为中文。

**动作：** 导出Markdown再打开。

**必须断言：** UTF-8内容完整无乱码。

**必须排除：** 可视化导出需要离开当前浏览器仍可读。



## T060-C02｜危险名称

**前置：** View名含路径分隔和系统保留字符。

**动作：** 点击下载。

**必须断言：** 得到安全文件名。

**必须排除：** 文件名不能控制服务器或用户路径。



## T060-C03｜秘密检查

**前置：** 设置中有测试Key。

**动作：** 导出脑图JSON。

**必须断言：** 无Key或Authorization标记。

**必须排除：** 视图不应携带服务配置秘密。



## T060-C04｜过期标记

**前置：** View已stale。

**动作：** 导出。

**必须断言：** 说明生成依据时间与过期状态。

**必须排除：** 导出后用户更容易误认为最新结论。



## T060-C05｜可重复编译

**前置：** 同一树导出两次。

**动作：** 比较正文。

**必须断言：** 结构一致，仅允许明确导出时间差异。

**必须排除：** 导出不应重新调用模型改变内容。



## T060-C06｜无额外格式

**前置：** 用户打开导出菜单。

**动作：** 检查可选功能。

**必须断言：** 只提供已实现格式，不显示无效PDF按钮。

**必须排除：** 不能用不可用按钮制造完整感。
