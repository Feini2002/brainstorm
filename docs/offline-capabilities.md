# 离线可用范围

这份说明按**具体功能**划分可用性，而不是笼统承诺“离线也能用”。判断依据是代码与浏览器实测，
不是设计意图。相关任务：[T024 无 Key 与断网可用路径](04_tasks/G1/T024_offline_crud.md)。

## 1. 两种“离线”必须分开

| 条件 | 含义 | 影响 |
| --- | --- | --- |
| **外网不可达** | 能访问 `127.0.0.1`，连不上外部域名 | 只有需要模型的操作受影响 |
| **本地服务已停止** | Node 进程不在运行 | 全部读写不可用，因为没有后台服务 |

本工具是本地 Web 应用，不是 PWA：没有 Service Worker，也没有后台任务。本地进程关闭时，
页面无法读写数据，也不会“稍后自动同步”。这正是 T024-R06 要求写清楚的边界。

## 2. 无外网、无 Key 时仍然可用的功能

以下功能在没有任何模型配置、且外部域名全部不可达时全部可用。它们不经过 `LLMService`，
也不先检查 Key 是否存在（T024-R02）：

- 采集：保存一个词、一句话或一段资料；原文先落盘并拿到 ID。
- 收件箱时间线、资料库列表与详情抽屉。
- 关键字检索（字面匹配，非语义）、类型/状态/标签筛选、游标分页。
- 人工编辑标题、摘要、类型、重要度、标签、关键词、来源引用。
- 人工建立关系（含方向语义），以及关系审核的接受、拒绝、重新确认。
- 删除记录及引用失效提示。
- 跨视图选择与数量预算。
- 标签词典。

以上每一条都有浏览器级证据：见 `tests/e2e/offline-crud.spec.ts` 的 T024-C01/C02/C03/C06。

## 3. 需要外部服务的功能

只有“产生新的 AI 结果”需要外部模型连接：

| 功能 | 状态 |
| --- | --- |
| 保存并整理（抽取元数据与建议关系） | 需要模型；无配置时先保存原文，再说明缺少配置 |
| 连接测试 | 需要模型 |
| 生成新的脑图 / 流程图投影 | 需要模型 |

已经生成并保存的视图**不需要**模型即可重新渲染：脑图用本地 Markmap，流程用本地 Mermaid，
关系图用本地 ReactFlow + Dagre。渲染不发起任何网络请求。

无配置时点击“保存并整理”的行为（T013-R06 / T025-R04）：**原文照常保存**，然后明确提示
“整理功能需要先在设置里配置模型”。原文不会因为缺少 Key 而丢失。

## 4. AI 失败不牵连本地功能

模型调用失败（超时、断网、401、限流）只影响那一次 AI 操作：

- 已经保存的知识仍可读取、编辑、检索、导出。
- 输入框不会被错误提示遮住，可以立刻记录下一条（T024-R04）。
- 失败说明与草稿放在一起，切换页面后仍在。
- 没有全局 loading 锁，也没有把失败改写为“保存失败”。

证据：`tests/e2e/offline-crud.spec.ts` 的 T024-C05、`tests/e2e/save-races.spec.ts` 的 T025-C03。

## 5. 前端资源的本地化

页面基础字体、图标与脚本全部来自本地构建，不依赖 CDN 或远端字体（T024-R01）：

- `src/app/layout.tsx` 不再使用 `next/font/google`。
- 字体栈是系统 UI 字体（`src/app/globals.css` 的 `--font-sans-stack`）。
- 图标用字符/内联 SVG，不加载外部图标字体。

e2e 用例在**阻断全部外部域名**的条件下浏览六个页面并检查关键控件，同时断言没有任何外部请求
（T024-C03/C06）。截图与网络记录见 `implementation/progress/evidence/`。

## 6. 测试用的“断网”是怎么实现的

`tests/e2e/support/harness.ts` 拦截页面发出的每一个请求：

- `127.0.0.1` / `localhost` 的请求放行并记录；
- 其它所有主机一律 `route.abort('internetdisconnected')`，并记为 `blocked`。

这**不是**浏览器的 `offline` 模式。离线模式会把 `127.0.0.1` 一起断掉，那恰恰会使“本地优先”
无法被验证；本方案保留本机可达、只阻断外网，与 T024-R05 的要求一致。

因此每个用例都能给出两张清单：真实发出的请求，以及被拦截的外网请求。断言“没有外部调用”
时有具体记录可查，而不是只凭没有报错。

## 7. 未执行或未覆盖的事项

- 真实模型连接的可用性需要用户自己的 API Key，未在本机验证；G2 起用替身完成结构断言。
- 多浏览器与真机（手机/平板）未验证；本版只面向本机桌面浏览器。
- 未做 CSP 生产配置；`docs/03_contracts/05_settings_and_security.md` §5 要求分别实测
  Mermaid/Markmap 所需样式后再定，不预填未经证实的万能头。
