# T038｜整理字段应用与人工保护


任务编号：**T038**。所属阶段：**G2｜LLM整理与可靠运行**。状态：**待实现**。这是实施规格，不是已经执行的测试报告。

## 一、目标与用户可见结果

把模型的整理建议有选择地写入条目，保证用户手工维护的字段和原始材料不被批量覆盖。

该任务负责的是“领域不变量、版本与用户控制权”。合格实现不仅要在正常样例上工作，还必须守住这里规定的不变量。它不授权扩大MVP范围，也不授权替换整个技术栈。功能完成以后，应能通过本任务验收文件独立判断，而不是依赖实现者口头说明。

## 三、输入与输出契约

**输入：** 验证后的title summary type tags keywords importance、当前manualFields、输入revision和rawVersion。

**输出：** 原子应用的可允许字段、新revision、structuredBaseRawVersion、跳过字段说明。

本任务允许：维护实体身份、人工决定、状态转移和原子更新。边界以外：不得让Renderer格式或模型自由文本决定领域存储结构。输入来自外部时先验证，内部状态只由该层合法操作修改。字段名、枚举、数量限制和版本行为以规范契约为准，不依据UI文案自行创造另一种类型。

## 五、必须逐条落地的规则

### T038-R01

模型永远不能写capturedText、rawText、sourceRef、createdAt、ID和系统版本；它只提供允许的整理字段。

### T038-R02

manualFields里的字段保留原值，未锁字段才更新；所有字段被锁也可以完成运行但需说明无字段应用。

### T038-R03

应用前再次比较revision与rawVersion；冲突整次不提交，不采用逐字段猜测合并。

### T038-R04

标签通过同一TagRepository规范化，关键词去重并限长；不能绕过已有人工编辑规则。

### T038-R05

成功把structuredBaseRawVersion设为本次原文版本，revision只增加一次，status与错误字段统一更新。

### T038-R06

importance是排序提示不是客观价值评分，模型不得根据内容敏感程度或个人偏好强行提高。

## 六、装配顺序与局部实现策略

第一步确认前置输出已经可读取，列出本任务实际要消费的字段与函数。不要先画完整界面再发现上游没有需要的版本或ID。第二步在责任层实现核心转换或操作，先用最小输入验证成功分支，再加入边界输入和错误分支。

第三步连接上下游：领域Service连接仓储、模型结果和用户动作；所有页面通过同一契约观察状态而不各自推导一套规则。第四步把状态变化和错误反馈接到实际使用入口，明确何时允许用户再次操作。第五步运行本任务的正常和反例用例，复核不应发生的副作用，而不是只观察表面结果。

最后执行与本任务相关的类型检查、单元或集成测试，并在必要时跑浏览器。局部实现通过后再执行上一个Gate的冒烟回归，防止共享模块改动破坏已经可用的采集与数据路径。

## 七、状态、错误与一致性检查

重点观察：Item revision/rawVersion、Relation审核与证据、Run终态或View来源。在测试前记录基线，在测试后比较目标变化与未授权变化。发生错误时必须遵循统一错误协议，不能把异常吞掉后返回空成功，也不能用随机重试掩盖不确定的提交状态。

关键负向要求：原文不会无提示消失，人工修改不被静默覆盖，迟到响应不复活已终止操作。除了断言目标结果，还要确认不相关实体未改变；跨实体误写也是失败。若当前任务涉及外部依赖，不可用时给出明确降级或阻塞说明；无需外部依赖的部分仍应保持可用。

## 八、验收、证据与恢复

本任务有6个具名验收场景，详见独立用例文档。执行观察方式：先读取目标及依赖实体的版本、状态和关系，再触发动作并复核所有应变与不应变字段。验收证据包含实际输入或最小fixture、动作、预期与实际结果、命令退出码、相关实体ID或版本以及失败定位。

清理与恢复：恢复本用例专用fixture并清理运行记录；对不可逆动作使用隔离数据库而不是回滚真实资料。没有执行的用例只能标为未执行或环境阻塞。使用测试替身的结果不得写成真实外部服务已经通过；模拟的成功响应也不能出现在正式产品中冒充功能。

## 九、交接给下一个任务

交接时说明新增公开函数、DTO或组件的名字，列出已验证规则和仍阻塞的事项。不要把实现细节藏在临时聊天记录里。后续任务只应依赖本任务稳定输出，不应读取私有内部状态或复制SQL。改变契约必须同步其权威文件和所有受影响用例。

完成标准是：规则有实现位置，用例有执行证据，错误有可恢复路径，共享数据没有新增歧义。不能用“页面已经画出来”代替这个标准。
