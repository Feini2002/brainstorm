# 六个页面、公共组件和交互状态设计


## 1. 视觉层目标

界面不需要成为新的Notion，但必须让用户清楚“刚刚保存了什么、哪些是AI推断、现在看的是哪批材料”。桌面布局左侧窄导航，右侧内容区；视图页给画布更多面积，普通页优先可读。中文文案简短，组件使用一致的间距、按钮层级和空态，不为了装饰添加仪表盘或大量统计卡。

设计tokens集中在CSS变量：背景、表面、正文、次要文字、边框、焦点、警告、错误、成功、建议关系、已确认关系。文字颜色对比须人工与自动检查，不只靠颜色表示状态。各页面共享Button、TextInput、TextArea、Select、Dialog、Drawer、Toast、EmptyState、InlineError和LoadingIndicator；不写六套不同错误弹窗。

## 2. Inbox

上方采集框具备大textarea、来源类型、可选来源链接/备注、字数、仅保存、保存并整理。原文允许一个词，标题不是必填。Ctrl/Cmd+Enter默认仅保存，避免快捷键无意识付费；保存并整理可用独立按钮，第一次使用解释会发送本条和受限旧笔记候选到用户配置的服务。

保存成功前输入不清空；保存后保持滚动位置并在下方最近记录出现卡片。保存成功但AI失败显示双阶段结果“已保存；整理失败”，保留Retry；不能红色整页提示“保存失败”。用户未配Key时仅保存正常可用，AI按钮提示去设置，不把整个应用锁在配置向导里。

草稿默认仅页面内存，刷新前有未提交内容提示。为避免未经同意在localStorage留下敏感原文，MVP不实现永久自动草稿；后续需要时专门设计本地draft表与清理。响应丢失时不要先清空输入；用同captureRequestId确认保存状态。

## 3. Library与详情

Library顶部搜索、类型、标签、状态、排序；筛选变化重置游标，结果显示真实匹配数。列表卡片显示标题或rawText安全截断、摘要、标签、来源、时间、状态及AI建议数量。不默认在列表加载全部原文和全部图历史，分页每页三十。

详情Drawer统一供Library、Graph、Mindmap来源Outline和Flow来源面板复用。先展示当前rawText，再可展开最初capturedText；显示摘要与人工锁标记、类型、标签、关键词、重要性、来源和关系。人工编辑后标明“手工保留”，提供明确解锁，不用用户猜为什么重整不改摘要。

有未保存编辑时关闭Drawer需确认或保留草稿；按Esc与点击遮罩行为一致。删除知识要显示标题和会删除关联边的提示；删除View用不同文案。版本冲突时显示服务器已更新，不直接把当前输入覆盖掉。

## 4. Graph

工具条包含范围选择、审核状态、标签/类型、AI最低评分、显示过期关系、自动布局、保存布局。人工边score=null不受AI阈值误伤。屏幕应区分accepted实线、suggested虚线或徽标、stale灰化并有文字，不能只用红绿区分。拒绝边默认隐藏。

点击节点打开详情而不改变选中来源集合；多选知识使用专门选择状态。连线创建先弹关系类型/方向/理由确认，再走手工关系API；拉出一条视觉线不等于数据库已确认。默认Delete键禁用知识删除。节点位置变动仅标“布局未保存”，不标笔记已编辑。

超过二百节点/六百边时说明“当前仅显示部分范围”，显示匹配与展示数量并引导缩小范围。无关系时仍显示孤立节点，并解释可手工连接或逐条整理，不用无限loading代替空图。

## 5. Mindmap与Flow

两页共享SourcePicker、SelectionSummary、GenerateAction、RunStatus、SavedViews、SourceOutline和ExportMenu。生成前明确选择数量、可发送文本预算和用户意图；运行中显示阶段而不是虚假百分比，因为外部模型不提供可验证进度。取消页面等待不承诺远端请求已经免单取消。

Mindmap提供树状可视化与文本大纲切换。Flow在图旁保留安全源码/来源说明作为降级阅读，不允许用户随意编辑源码后执行。假设边必须有文字说明。生成失败保留上一次成功结果和当前意图，不能把画面全清空强迫重新选择。

历史视图列表显示名字、生成时间、来源数和过期标记。重新生成创建新条目，旧视图可另行删除。查看历史不会自动产生新模型请求。无Key时仍能打开已保存视图和导出。

## 6. Settings

分为模型连接与本地数据两区。连接区显示adapter、Base URL、最终endpoint预览、model、Key状态、JSON格式档位、token参数档位、可选一次修复。高级字段默认折叠但解释清楚，不能自动猜测模型能力并隐藏实际请求变化。

测试当前草稿与保存配置是两个按钮。测试成功不表示已经保存；保存成功不表示已经验证模型可用。Key保留/替换/删除可用明确单选或对应按钮，删除需确认；切换origin保留Key需再次确认。页面的描述应避免“Key绝对安全”，如实写本机明文、逻辑导出不包含。

数据区显示相对存储位置、逻辑导出、空库恢复、诊断下载及备份提醒。不要加一键删除整个.data的诱人按钮。诊断可预览，导出知识与导出诊断分开。

## 7. 快捷键、可访问性与反馈

所有按钮有文字或aria-label；表单错误与字段关联；Drawer管理焦点、关闭后返回触发位置；键盘可完成保存、搜索、来源选择和查看原文。图形浏览提供等价来源列表，不要求必须能用鼠标理解所有知识。

Loading仅覆盖需要等待的区域，后台一条笔记整理不禁用其他笔记保存。Toast不作为唯一错误载体，重要失败在相关控件旁保留。筛选结果为空、库为空、加载失败、未配置Key、过期图是五种不同状态，不能都画同一个空盒子。
